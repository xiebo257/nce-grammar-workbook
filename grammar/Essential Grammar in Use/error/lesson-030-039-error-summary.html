Recurring Mistake Patterns

5 errors
Wrong pronoun / subject
  • Karen → he (should be she) — L32
  • I/we → kept as I/we in questions (should be you) — L33
  • there were → should be negative (contrast clue) — L38
  • it → should be there (rain amount) — L39
Fix: Match pronouns to names. Convert I/we → you in questions. Check contrast clues for polarity.
4 errors
Wrong tense for time marker
  • had to for future (should be must) — L31
  • must for past (should be had to) — L31
  • present perfect for past (when we arrived) — L38
  • present perfect for present fact (Now) — L38
Fix: Check the time marker first — past → was/had to, now → is/must, result-up-to-now → has been.
3 errors
Modal + wrong verb form
  • have to + waiting → have to + wait — L33
  • must/have to confusion (external → have to) — L33
  • There's (present) instead of There's been (perfect) — L38
Fix: All modals (can, could, should, must, have to) take the bare infinitive. Never -ing, never "to".
3 errors
Wrong content / activity
  • borrow vs lend (I borrow, you lend) — L30
  • "used to be new" instead of "used to be a hotel" — L36
  • "have long hair" — not Karen's activity — L36
Fix: Read the prompt carefully. Don't reuse words from other exercises. borrow = take, lend = give.
2 errors
it vs there confusion
  • it's for new info → should be there's — L37
  • it for rain amount → should be there — L39
Fix: there = existence/amount/new info. it = identity/quality/known thing.
