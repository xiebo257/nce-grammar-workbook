Unit 40 — I am, I don't etc.

What it means

Auxiliary verbs (am/is/are, do/does/did, have/has/had, can/could, will, etc.) can be used alone to avoid repeating the main verb. The auxiliary carries the full meaning.

PatternUseExample
am/is/are (not)avoid repeating adjective/nounKate wasn't hungry, but we were. (= were hungry)
do/does/did (not)avoid repeating main verbI like cats, but my friends don't. (= don't like cats)
have/has (not)avoid repeating past participleI've finished, but she hasn't. (= hasn't finished)
can/could (not)avoid repeating main verbI can swim, but I couldn't when I was 5.
When to use auxiliary alone
  • When the main verb is already clear from context → just use the auxiliary: "Kate wasn't hungry, but we were."
  • In short answers to yes/no questions → reuse the question's auxiliary: "Is it snowing?" → "No, it isn't."
  • In short answers with did → "Did you buy anything?" → "Yes, I did."
Why the auxiliary carries the meaning

The auxiliary (be/do/have/can) already tells you the tense and polarity (positive/negative). Since the context has already established the main verb, repeating it is unnecessary:

  • "I was working, but my friends weren't." — "weren't" = "weren't working" (past continuous, negative)
  • "Did you go out?" — "Yes, I did." — "did" = "did go out" (past simple, positive)

A full sentence like "No, it is windy and raining" answers the question but misses the exercise's point: practicing short auxiliary answers.

Pitfalls
  • ❌ "my friends wasn't" → ✅ "my friends weren't" — "my friends" is plural, so use were (not was). was is only for I/he/she/it.
  • ❌ "I'm like cats" → ✅ "I like cats" — "I'm" (= I am) takes an adjective or noun ("I'm American", "I'm happy"), not a verb phrase. "like cats" needs "I like" (subject + verb), not "I'm like".
  • ❌ Short answers with full sentences → ✅ Use short auxiliary form: "No, it isn't." / "Yes, I did."
Form rules
  • was → I/he/she/it (singular). were → we/you/they (plural).
  • you always takes were (never was) — even for singular "you".
  • Short answer = subject + auxiliary (+ n't): "Yes, I did." / "No, it isn't." / "Yes, she has."
  • "I'm" = I am → followed by adjective/noun, not verb phrase.

Unit 41 — Have you? Are you? Don't you? etc.

What it means

Two structures that echo back what someone said: reply questions and question tags.

StructureFormUseExample
Reply questionAuxiliary + subject?show interest, echo a statement"I've bought a car." → "Have you?"
Question tag (positive → negative)Statement, + negative tag?ask for confirmation"It's nice, isn't it?"
Question tag (negative → positive)Statement, + positive tag?ask for confirmation"You don't smoke, do you?"
When to use reply questions vs question tags
  • Reply questions → respond to someone's statement to show interest: "Kate phoned me." → "Did she? What did she say?"
  • Question tags → ask for agreement/confirmation at the end of a statement: "Jane was at the party, wasn't she?"
Why tags reverse polarity

Question tags "reverse" the polarity of the statement:

  • Positive statement → negative tag: "It's nice, isn't it?"
  • Negative statement → positive tag: "You don't smoke, do you?"

The tag uses the same auxiliary as the statement, but flips positive↔negative. If there's no auxiliary (present/past simple), use do/does/did.

Correct examples
  • ✅ "Kate phoned me last night." → "Did she?" (Kate = female → she; past simple → did)
  • ✅ "These flowers are nice, aren't they?" (These flowers = plural → they; are → aren't)
  • ✅ "Jane was at the party, wasn't she?" (Jane = singular female → she; was → wasn't)
  • ✅ "I didn't go to work yesterday." → "Didn't you?" (negative → positive reply question)
Pitfalls
  • ❌ "Kate phoned." → "Did he?" → ✅ "Did she?" — Kate is a female name → she.
  • ❌ "These flowers are nice, isn't it?" → ✅ "aren't they?" — "These flowers" = plural → they → aren't they?
  • ❌ "Jane was at the party, aren't they?" → ✅ "wasn't she?" — wrong pronoun (they → she) and wrong verb (are → was). Match both pronoun AND verb to the statement.
  • ❌ Typo: "Dind't you?" → ✅ "Didn't you?" — missing 'd'.
Form rules
  • Match the pronoun to the subject: Kate → she; Tom → he; these flowers → they; the book → it.
  • Match the verb to the statement's tense: was → wasn't; are → aren't; have → haven't.
  • Reply question = auxiliary + subject + "?" (same polarity as statement)
  • Question tag = reverse polarity: positive statement → negative tag; negative → positive.

Unit 42 — too/either; so am I / neither do I etc.

What it means

These structures express agreement — saying "me too" or "me neither" in a more formal way.

Agreement typeWordStructureExample
positive agreementtoosubject + auxiliary + too"I'm happy." → "I am too."
negative agreementeithersubject + negative auxiliary + either"I don't smoke." → "I don't either."
positive agreementSoSo + auxiliary + subject"I can swim." → "So can I."
negative agreementNeitherNeither + auxiliary + subject"I'm not tired." → "Neither am I."
When to use too/either vs So/Neither
  • too (positive) / either (negative) → placed at the end: "I am too." / "I don't either."
  • So (positive) / Neither (negative) → placed at the front, with auxiliary before subject: "So am I." / "Neither do I."
  • Both forms mean the same thing — they're just different word orders.
Why the auxiliary must match the statement's verb

In "So + auxiliary + I" and "Neither + auxiliary + I", the auxiliary must match the verb in the original statement:

StatementTenseAuxiliaryAgreement
"I need a holiday"present simpledoSo do I.
"I can ride a bike"modalcanSo can I.
"I slept well"past simpledidSo did I.
"I go to the cinema"present simpledoSo do I.
"I'm not going out"negativeamNeither am I.

Never use the main verb in the So/Neither pattern: "So do I" (not "So need I"). Never default to "am" for all verbs — match the auxiliary to the verb type.

Correct examples
  • ✅ "I need a holiday." → "So do I." (present simple → do)
  • ✅ "I'm not going out tomorrow." → "Neither am I." (negative → Neither)
  • ✅ "I can ride a bike." → "So can I." (modal → can)
  • ✅ "I slept well last night." → "So did I." (past simple → did)
  • ✅ "I go to the cinema a lot." → "So do I." (present simple → do)
Pitfalls
  • ❌ "So need I" → ✅ "So do I" — never use the main verb; always use the auxiliary (do/does/did/can/will).
  • ❌ "So am I" (for "I can ride") → ✅ "So can I" — match the auxiliary to the statement's verb (modal → can).
  • ❌ "So am I" (for "I slept well") → ✅ "So did I" — past simple → did, not am.
  • ❌ "So am I" (for "I go to the cinema") → ✅ "So do I" — present simple → do, not am. Never default to "am" for everything.
  • ❌ "So am I" (for "I'm not going out") → ✅ "Neither am I" — negative statement → Neither, not So.
Form rules
  • So + auxiliary + subject → positive agreement (So do I / So can I / So did I)
  • Neither + auxiliary + subject → negative agreement (Neither am I / Neither do I)
  • Auxiliary must match the statement: present simple → do/does; past simple → did; continuous → am/is/are; modal → can/will/must
  • Positive → So; negative → Neither. (Opposite of what you might expect — So for positive, Neither for negative.)

Unit 43 — isn't, haven't, don't etc. (negatives)

What it means

Forming negative sentences by adding not (or the contraction n't) to the auxiliary verb.

Tense / Verb typeNegativeExample
present simpledon't / doesn'tI don't know. / She doesn't know.
past simpledidn'tThey didn't understand.
present continuousam not / isn't / aren'tI'm not working. / She isn't working.
present perfecthaven't / hasn'tI haven't finished. / She hasn't finished.
modal (can/will/should)can't / won't / shouldn'tI can't swim. / You shouldn't smoke.
have gothaven't got / hasn't gotI haven't got a car. / He hasn't got a car.
When to use which negative form
  • Present simple → don't / doesn't + verb: "I don't know." / "He doesn't know."
  • Past simple → didn't + verb: "They didn't understand."
  • Present perfect → haven't / hasn't + past participle: "She hasn't worn it yet."
  • Advice/prohibition → shouldn't / mustn't: "You shouldn't drive so fast. It's dangerous."
  • Have got → haven't got / hasn't got: "He hasn't got a car."
Why different auxiliaries for different tenses

Each tense has its own auxiliary for negatives:

TenseAuxiliaryWhy
present simpledo/does + notno other auxiliary available
past simpledid + notno other auxiliary available
present perfecthave/has + not"have" is the auxiliary
present continuousam/is/are + not"be" is the auxiliary
modalmodal + notmodal is the auxiliary

The key rule: 3rd person singular (he/she/it) uses doesn't (present simple), hasn't (present perfect), isn't (continuous) — never don't, haven't, or aren't.

Correct examples
  • ✅ "They didn't understand." (not "There didn't understand" — there ≠ they)
  • ✅ "She hasn't worn it yet." (she = 3rd person singular → hasn't, not haven't)
  • ✅ "You shouldn't drive so fast. It's dangerous." (advice → shouldn't, not don't)
  • ✅ "He hasn't got a car." (he = 3rd person singular → hasn't, not haven't)
  • ✅ "He went out last night." (past simple positive = went, not "did go")
Pitfalls
  • ❌ "There didn't understand." → ✅ "They didn't understand." — "there" = existence (there is/are); "they" = pronoun for people. Don't confuse them!
  • ❌ "she haven't" → ✅ "she hasn't" — she = 3rd person singular → hasn't. "have" is for I/you/we/they only.
  • ❌ "he haven't got" → ✅ "he hasn't got" — same rule: he = 3rd person singular → hasn't.
  • ❌ "You don't drive so fast. It's dangerous." → ✅ "You shouldn't / mustn't drive so fast." — "It's dangerous" signals advice/prohibition, not a factual statement. Use shouldn't/mustn't.
  • ❌ "He did go out last night." → ✅ "He went out last night." — past simple positive = went (past tense form). "did go" is emphatic only (used for emphasis: "He did go!").
Form rules
  • 3rd person singular (he/she/it) → doesn't (present), hasn't (perfect), isn't (continuous). Never don't/haven't/aren't.
  • Past simple negative → didn't + bare verb: didn't understand (not "didn't understood").
  • Past simple positive → verb past tense: went / bought / understood. Not emphatic "did go".
  • there = existence (there is/are). they = pronoun for people/things. Never mix them up.
  • "It's dangerous" → signals advice/prohibition → use shouldn't or mustn't, not don't.
