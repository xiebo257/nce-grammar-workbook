19.5 #5 Write sentences about yourself. Begin with: I've had ... I've had lunch since 12.00. (better: I've had this phone for two years / I've had a headache since morning) word choice "lunch" is an event, not a possession — "have had lunch since 12:00" is awkward.
Rule: active vs passive in present perfect
has played = active (he plays). has been played = passive (the piano is played by someone). For a person doing an activity, always use active: has played / has been playing.
