Lesson 40 — I am, I don't etc.

#QuestionYour answerCorrectIssue
40.2 #3 "I was working, but my friends _____."
Write negative verb		 wasn't weren't subject-verb agreement my friends = plural → weren't. was is singular: I/he/she/it; were is plural: we/you/they.
40.4 #4 "I'm" frame — write about yourself like cats, but my friends don't. American, but my husband isn't. auxiliary form "I'm like cats" doesn't work — "I'm" takes adjective/noun, not verb phrase. "like cats" needs "I like" not "I'm".
40.6 #4 "Is it snowing?" — write short answer No, it is windy and raining. No, it isn't. short answer format Full sentence, not short auxiliary form. Exercise teaches short answers: "No, it isn't."

Rule: short answers reuse the question's auxiliary
"Is it snowing?" → "No, it isn't." (not a full sentence). "Did you buy anything?" → "Yes, I did." The auxiliary carries the meaning — no need to repeat the main verb.

41.3 #2 "These flowers are nice, _____?"
Question tag		 Isn't it? aren't they? subject-verb agreement These flowers = plural → they → aren't they? (not it → isn't it).
41.3 #3 "Jane was at the party, _____?"
Question tag		 aren't they? wasn't she? wrong pronoun + verb Jane = singular female → was → wasn't she? (wrong pronoun: they → she; wrong verb: are → was).
Rule: question tags — match pronoun and verb to subject
Tags use the same subject pronoun and verb tense as the statement. "Jane was..." → "wasn't she?" (not "aren't they?"). "These flowers are..." → "aren't they?" (not "isn't it?").

Lesson 42 — too/either; so am I / neither do I etc.

#QuestionYour answerCorrectIssue
42.2 #4 "I need a holiday."
So...I or Neither...I		 So need I. So do I. wrong auxiliary Use auxiliary "do", not the main verb "need". Pattern: So + auxiliary + I, never the main verb.
42.2 #10 "I'm not going out tomorrow."
So/Neither		 So am I. Neither am I. polarity error Negative statement → Neither, not So. Positive → So; negative → Neither.
42.3 #2 "I can ride a bike."
About yourself		 So am I. So can I. wrong auxiliary Modal "can" → use "can" as auxiliary, not "am". Auxiliary must match the statement's verb.
42.3 #6 "I slept well last night." So am I. So did I. wrong auxiliary Past simple → use "did", not "am". Auxiliary matches the statement's verb tense.
42.3 #12 "I go to the cinema a lot." So am I. So do I. wrong auxiliary Present simple → use "do", not "am". Never default to "am" for everything.
Rule: So/Neither + auxiliary + I
The auxiliary must match the statement's verb: present simple → do/does; past simple → did; present continuous → am/is/are; modal → can/will/must. Never use the main verb (So do I, not So need I). Positive → So; negative → Neither.

Lesson 43 — isn't, haven't, don't etc. (negatives)

#QuestionYour answerCorrectIssue
43.2 #3 "They understood."
Make negative with don't/doesn't/didn't		 There didn't understand. They didn't understand. wrong word there ≠ they. "there" = existence; "they" = pronoun for people.

About Gary		 He haven't got a car. He hasn't got a car. subject-verb agreement he = 3rd person singular → hasn't, not haven't.

About Gary		 He did go out last night. He went out last night. auxiliary form Past simple positive = went (not emphatic "did go"). "did go" is emphatic only.
Rule: negatives and 3rd person singular
3rd person singular (he/she/it) → hasn't / doesn't (not haven't/don't). Past simple negative → didn't + verb. Past simple positive → verb past tense (went), not emphatic "did go".

Recurring Mistake Patterns

3 errors
Subject-verb agreement
  • my friends (plural) → wasn't → should be weren't — L40
  • she → haven't → should be hasn't — L43
  • he → haven't → should be hasn't — L43
Fix: Plural subjects (we/you/they) → were/aren't/have. 3rd person singular (he/she/it) → was/isn't/has.
2 errors
Wrong pronoun / word
  • Kate → he (should be she) — L41
  • they → there (should be they) — L43
  • These flowers → it (should be they) — L41
  • Jane → they (should be she) — L41
Fix: Match pronoun to subject. Kate/Jane → she. Plural nouns → they. "there" = existence, "they" = people/things.
3 errors
So/Neither + wrong auxiliary

  • "I can ride" → So am I → should be So can I — L42
  • "I slept" → So am I → should be So did I — L42
  • "I go" → So am I → should be So do I — L42
Fix: Auxiliary must match the statement's verb (can/did/do). Never use the main verb. Never default to "am" for everything.
1 error
Polarity error (So vs Neither)
  • "I'm not going out" → So am I → should be Neither am I — L42
Fix: Positive statement → So + auxiliary + I. Negative statement → Neither + auxiliary + I.
2 errors
Auxiliary form errors

  • Emphatic "did go" instead of past simple "went" — L43
Fix: "I'm" = I am → takes adjective/noun (American, happy). Past simple positive = verb past tense (went), not "did go".
