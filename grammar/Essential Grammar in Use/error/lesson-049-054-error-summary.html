Rule: Indirect questions — word order and tense
Indirect questions use subject + verb order (no inversion). Keep the same tense as the direct question. 3rd person singular still takes -s: "where Susan works", "what time he gets up".

Rule: go + -ing (activities)
go + -ing for activities: go shopping, go swimming, go skiing. No "to" before the -ing word. "go to the shops" (place) vs "go shopping" (activity).

#QuestionYour answerCorrectIssue
53.2 #3 "You should go to the doctor." (I advised _____) he to go to the doctor. him to go to the doctor. object pronoun he → him (object pronoun after "advised"). Subject: he; Object: him. Verbs like advised/told/asked take object pronouns.

Rule: verb + object + to + infinitive
want/tell/advise/ask/teach + object pronoun + to + infinitive: "I told him to go." Use object pronouns (me/him/her/us/them), not subject pronouns (he/she/they).

Rule: Purpose with to + infinitive
Use to + infinitive to express why: "I went to the shop to buy milk." Indirect questions inside purpose clauses keep subject + verb order: "to see who it was" (not "who is it").

Recurring Mistake Patterns

3 errors
3rd person singular → -s
  • Susan works (not work) — L49
  • the meeting begins (not begin) — L49
  • he gets up (not get up) — L49
Fix: Even in indirect questions, 3rd person singular takes -s. "where Susan works", "what time he gets up".
2 errors
Indirect question word order & tense
  • "who is it" → "who it was" (subject + verb, past tense) — L54
  • "has lived" → kept as "lived" (should keep same tense) — L49
Fix: Indirect questions use subject + verb (no inversion). Keep the same tense as the direct question.
2 errors
to + infinitive vs bare infinitive
  • would like → to + inf (to go, not go) — L51
  • "go to shopping" → "go shopping" (no "to" before activity) — L52
Fix: would like always takes to + infinitive (never bare). go + -ing for activities (no "to").
1 error
Object pronouns after verbs
  • he → him (after advised) — L53
Fix: Subject vs object: I/me, he/him, she/her, we/us, they/them. Verbs like advised/told/asked take object pronouns.
3 errors
Wrong verb or word
  • watch vs listen (TV vs radio) — L51
  • went go → went to (preposition) — L49
  • play piano → play the piano (instruments take "the") — L53
Fix: Match verb to media type (watch TV, listen to radio). Instruments always take "the".
1 error
go + -ing pattern
  • "go to shopping" → "go shopping" — L52
Fix: Activity = gerund, no "to" before -ing. "go shopping / swimming / skiing". "go to the shops" (place needs "to").
