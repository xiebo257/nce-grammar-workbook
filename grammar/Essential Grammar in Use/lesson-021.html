21.1 Write sentences from these words

Some of the sentences are questions. Sentences 1–7 are present.

  1. (the office / clean / every day) The office is cleaned every day.
  2. (how often / these rooms / clean?) How often are these rooms cleaned?
  3. (glass / make / from sand) Glass
  4. (the windows / clean / every two weeks)
  5. (this room / not / use / very much)
  6. (we / allow / to park here?)
  7. (how / this word / pronounce?)

Sentences 8–15 are past.

  1. (the office / clean / yesterday) The office was cleaned yesterday.
  2. (the house / paint / last month) The house
  3. (my phone / steal / a few days ago)
  4. (three people / injure / in the accident)
  5. (when / this bridge / build?)
  6. (I / not / wake up / by the noise)
  7. (how / these windows / break?)
  8. (you / invite / to Jon's party last week?)
