## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `one` / `ones` as noun substitute | `a new one`, `the red ones` | `one` replaces a singular noun, `ones` a plural noun. Match the number of the noun being replaced. |
| `Which ones?` vs `Which one?` | `Which ___?` after `cups` → `ones`; after `chair` → `one` | The question word takes the same number as the noun offered. |
| Adjective + `one`/`ones` | `the orange one`, `the old ones` | The adjective goes before `one`/`ones`; no noun after it. |
| Singular reply frame | `Here's a small box. (big)` → `This one isn't small. It's a big one.` | Use when the prompt is `Here's a …` (singular). `This one … a … one`. |
| Plural reply frame | `Here are some blue shoes. (grey)` → `These aren't blue. They're grey.` | Use when the prompt is `Here are some …` (plural). `These … They're …` — note: no `one`/`ones` in the plural frame. |
| Object-pronoun rewrite | `Give Helen …` → `Give her …` | Replace the recipient noun with an object pronoun; keep the rest. Tom/John → `him`, Jane/mother → `her`, students/children/boys → `them`, me and my friend → `us`. |
| Plural noun + verb agreement | `The knife … is` → `The knives … are` | Pluralise the subject noun **and** switch `is → are`. |
| Regular plurals | `bottles`, `plates`, `radios`, `ties`, `coats`, `flowers`, `books`, `carpets` | Add `-s` (or `-s` after vowel+o: `radios`). |
| Irregular plurals | `knife → knives` | `-fe`/`-f` often becomes `-ves`. |

## Key takeaway

- Section I is pure `one`/`ones` agreement — match the replaced noun's number. All ten correct.
- Section II has **two** reply frames keyed to the prompt's number: singular (`Here's a …`) → `This one isn't … It's a … one.`; plural (`Here are some …`) → `These aren't …. They're ….`. The one error (Q16) came from applying the singular frame to a plural prompt **and** recycling the wrong adjective pair — when the prompt is `Here are some grey hats. (white)`, use the plural frame with `grey`/`white`.
- Section III is object-pronoun substitution — keep the object phrase, swap only the recipient. All nine correct.
- Section IV is subject pluralisation with verb agreement (`is → are`), including the irregular `knife → knives`. All nine correct.
