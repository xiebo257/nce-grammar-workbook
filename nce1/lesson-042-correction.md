## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `Is there a/an...?` (countable) | `Is there an orange in that basket?` | Use `a`/`an` + singular countable noun for yes/no existence questions. End with `?`. |
| `Yes, there is.` / `No, there isn't.` | `Yes, there is.` / `No, there isn't.` | The short answer to `Is there...?` is `Yes, **there** is.` / `No, **there** isn't.` — not `it is/it isn't`. `there` is the existential subject; `it` would answer `Is it...?`. |
| `Is there any...?` (uncountable) | `Is there any tea in that cup?` | Use `any` + uncountable noun for yes/no existence questions. |
| `, too` on parallel question | `Is there a banana in that basket, too?` | The second question asks about an additional item — add `, too` to show "also/in addition". |
| `There isn't [noun] there.` | `There isn't a banana there.` | The negation uses `there` as the location adverb (replacing the full location phrase). |
| `some` in affirmative correction | `There is some sugar.` | After the negation, state what IS there using `some` + uncountable noun. |
| Section I four-line frame | `Is there [article] [noun1] in/on [location]?` / `Yes, there is.` / `Is there [article] [noun2] in/on [location], too?` / `No, there isn't. There isn't [article] [noun2] there.` | Four lines: question → yes → parallel question with `too` → no + negation with `there`. |
| Section II two-line frame | `Is there any [noun2] in/on [location]?` / `No, there isn't. There is some [noun1].` | Two lines: `any`-question about the negated item → no + `some`-affirmative of the stated item. |

## Key takeaway

- **Q2–Q5 — `Yes, it is.` → `Yes, there is.`** This is the core error in Section I. The question `Is there...?` uses the existential `there` as its subject — the short answer must echo `there`: "Yes, **there** is." The learner wrote "Yes, **it** is." which would answer "Is **it**...?" (a pronoun question), not "Is **there**...?" (an existence question). **Rule: `Is there...?` → `Yes, there is.` / `No, there isn't.` Never use `it` to answer a `there` question.**
- **Q2–Q5 — missing `?`.** Yes/no questions must end with a question mark: `Is there a map in that book**?**` — not a period. The learner used periods throughout.
- **Q2–Q5 — missing `, too`.** The second question asks about an additional item. The example shows `Is there a banana in that basket, too?` — the `, too` is required.
- **Q9 — wrong location.** The prompt says "in that **cup**" but the learner wrote "in that **bottle**." The location must match the original statement. Read the prompt carefully before writing the question.
- **Section II — `any`/`some` secure.** The `any` (question) vs `some` (affirmative) distinction is correctly applied in all 5 items. The two-line frame is well mastered — the only error is a location copy mistake in Q9.
