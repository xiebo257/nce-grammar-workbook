## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `some` + plural countable noun | `some knives and forks`, `some pens` | Use `some` for an unspecified quantity of plural countables in affirmative requests (`Give me some …, please`). |
| `one` / `ones` as noun substitute | `the big one`, `the red ones` | `one` replaces a singular noun, `ones` a plural one; match the number of the noun being replaced. |
| `Which one?` / `Which ones?` | `Which one?` (magazine/tie); `Which ones?` (knives/pens/umbrellas) | The question word agrees in number with the noun offered. |
| Article + adjective + `one` | `a yellow one`, `a green one` | Keep the article (`a`) and the adjective before `one`; no noun after it. |
| The + adjective + `ones` | `the blue ones`, `the ones on the table` | `the` (or no article after `Which`) + adjective + `ones` for a specific plural set. |
| Dialogue frame for Section II | `These, please. Those are <cue>.` | Choose `These` (near), reject `those` (far) by describing them with the cue adjective. |
| `These` vs `those` | `These, please. Those are very small.` | `These` = near set (wanted), `those` = far set (described/rejected). |

## Key takeaway

- Section I combines three small-word choices in one exercise: `some` for unspecified plural quantities, `one` for singular referents, `ones` for plural referents. The key is to read the noun being replaced — singular → `one`, plural → `ones` — and to use `some` only in the quantity blank before a plural noun.
- Section II is a fixed two-sentence frame: accept the near set (`These, please.`) and describe the far set with the cue (`Those are <adjective>.`). When the cue has a modifier (e.g. `very small`), carry it whole.
