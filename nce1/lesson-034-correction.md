## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| Just add `-ing` | `turning`, `walking`, `dusting`, `flying`, `crying` | Most verbs just add `-ing`. Verbs ending in consonant + `y` keep the `y` (`fly` → `flying`, `cry` → `crying`). |
| Drop silent `-e`, add `-ing` | `shining`, `taking`, `making`, `typing`, `shaving` | Verbs ending in silent `e` drop the `e` before `-ing`: `shine` → `shining`, `type` → `typing`. |
| CVC doubling: double the final consonant | `running`, `putting`, `shutting`, `sitting` | One-syllable CVC verbs (consonant-vowel-consonant) double the last consonant: `run` → `run-ning`, `put` → `put-ting`, `shut` → `shut-ting`. |
| No doubling when stress is on first syllable | `emptying` | Two-syllable verbs with stress on the first syllable do not double: `empty` → `emptying` (stress on EMP-, not -TY). |
