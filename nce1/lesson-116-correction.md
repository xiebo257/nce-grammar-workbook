## Usage table

| Pattern | Example | Practical reminder |
|---|---|---|
| Things | `something`, `anything`, `nothing` | These refer to things, not people. |
| People | `someone`, `anyone`, `nobody`, `no one` | Use a person-word after `know` when talking about people. |
| Unspecified place | `somewhere in the library` | One unknown location. |
| All or no places | `everywhere` / `nowhere` | Everywhere means all places; nowhere means no place. |
| Negative rewriting | `There isn't anything` → `There's nothing` | Remove `not` when replacing `anything` with `nothing`. |
| Uncountable noun | `There isn't any milk left. There's none left.` | Use singular `is` for milk, paper, and bread. |
| Plural count noun | `There aren't any grapes left. There are none left.` | Use plural `are` for grapes and envelopes. |

## Key takeaway

- Distinguish thing-words, person-words, and place-words by context.
- `None` does not force singular verb agreement: use `are` for plural grapes or envelopes and `is` for uncountable bread.
