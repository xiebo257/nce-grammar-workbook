## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `be` (nationality) | `Mr. Brown is English.` / `Kathy is American.` | State nationality with `be`: `is/are + nationality adjective`. |
| `come` (origin) | `He comes from England.` / `We come from Denmark.` | State origin with `come from`: `come/comes + from + country`. |
| `speak` (language ability) | `He speaks English.` / `They speak Dutch.` | State language ability with `speak`: `speak/speaks + language name`. |
| `be` (language identity) | `His language is English.` / `Their language is Dutch.` | State language identity with `be`: `is/are + language name`. |
| Four-part pattern: be/come/speak/be | `Kathy is American; she comes from the United States. She speaks English; her language is English.` | Nationality → origin → ability → identity. Apply consistently even when words like "English" or "Italian" can be both nationality and language. |
| `do` auxiliary in questions | `Where do they come from?` / `Do you come from France?` | Questions with action verbs use `do/does` + base verb. `are` + `come` is ungrammatical. The answer "Yes, we do" confirms `Do`. |
| Third-person singular `is` for things | `my language is Spanish` | "My language" is third-person singular → `is`, not `am` (first-person). |
| Number format | `three hundred and sixty-five` | `and` after `hundred` (British). Compound numbers 21–99 are hyphenated: `thirty-one`, `sixty-five`. |
| Frequency adverb + action verb | `It often snows.` / `It sometimes rains.` | Adverb goes **before** the action verb: `often snows`, `sometimes rains`. No `be` needed. |
