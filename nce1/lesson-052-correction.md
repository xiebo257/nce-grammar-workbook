## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `be` (nationality) | `Mr. Brown is English.` / `Kathy is American.` | State nationality with `be`: `is/are + nationality adjective`. |
| `come` (origin) | `He comes from England.` / `We come from Denmark.` | State origin with `come from`: `come/comes + from + country`. |
| `speak` (language ability) | `He speaks English.` / `They speak Dutch.` | State language ability with `speak`: `speak/speaks + language name`. |
| `be` (language identity) | `His language is English.` / `Their language is Dutch.` | State language identity with `be`: `is/are + language name`. |
| Correct pattern: be/come/speak/be | `Kathy is American; she comes from the United States. She speaks English; her language is English.` | The four-part pattern: nationality → origin → ability → identity. Don't swap the order. |
| `do` auxiliary in questions | `Where do they come from?` / `Do you come from France?` | Questions with action verbs use `do/does`: "Do you come...?" not "Are you come...?" The answer "Yes, we do" confirms `Do`, not `Are`. |
| Third-person singular `is` for things | `my language is Spanish` | "My language" is third-person singular → `is`, not `am` (first-person). |
| Number format | `three hundred and sixty-five` (British) / `three hundred sixty-five` (American) | `and` goes after `hundred` (British): "three hundred **and** sixty-five". Compound numbers 21–99 are hyphenated: `thirty-one`, `sixty-five`. |
| Frequency adverb + action verb | `It often snows.` / `It sometimes rains.` | Adverb goes **before** the action verb: `often snows`, not `it's often snows`. No `be` needed. |

## Key takeaway

- **Q1/Q2/Q5 — pattern swap.** The correct four-part pattern is **be** (nationality) / **come** (origin) / **speak** (ability) / **be** (identity). The learner swapped blanks 1 and 3: putting `speak` (ability) where `be` (nationality) should be, and `be` (nationality) where `speak` (ability) should be. Q8/Q9 (which the learner got right) establish the correct pattern with unambiguous words. **Rule: nationality first, language ability third — don't swap them.**
- **Q3 — `am` vs `speak`/`is`.** "I **am** Spanish" contradicts "I am Mexican" — the blank should be `speak` (language ability). "My language **am**" is wrong — `my language` is third-person → `is`. **Rule: match the verb's person to the subject. `I am` / `my language is`.**
- **Q6/Q7 — `are` + `come` is ungrammatical.** "Where **are** they **come** from?" and "**Are** you **come** from France?" are ungrammatical — `be` + `come` don't combine. Questions with action verbs use `do/does`: "Where **do** they come from?" / "**Do** you come from France?" The printed answer "Yes, we do" in Q7 confirms `Do`.
- **Q17 — `it's often snows`.** `it's` = `it is`, so "it is often snows" is ungrammatical. With action verbs, use adverb + verb: `it often snows` — no `be` needed. This was correctly applied in Lesson 51 (Q7: "It often snows").
- **Q13 — number format.** `three hundred sixty and five` is non-standard. The `and` goes after `hundred` (British: "three hundred **and** sixty-five"), and 21–99 are hyphenated (`sixty-five`).
- **Q14 — spelling `sping` → `spring`.** Missing `r`: s-p-r-i-n-g.

**Summary:** 9/18; the errors cluster around three issues: (1) the four-part be/come/speak/be pattern swap in Q1/Q2/Q5, (2) ungrammatical `are`+`come` in questions (Q6/Q7), and (3) translation slips in Section II (number format, spelling, `it's often snows`). Q8/Q9 demonstrate the correct pattern is mastered when the words are unambiguous — the challenge is applying it consistently when words like "English" and "Italian" can be both nationality and language.
