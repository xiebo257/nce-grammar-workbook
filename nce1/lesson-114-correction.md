## Usage table

| Pattern | Example | Practical reminder |
|---|---|---|
| Negative with `any` | `There aren't any flowers.` | Put `any` after the negative verb. |
| `No` before a noun | `There are no flowers.` | `No` directly determines the noun. |
| `None` replacing a noun | `There are none.` | Do not repeat the noun after `none`. |
| Present perfect with `any` | `She hasn't had any food.` | Preserve the original subject and main verb. |
| Present perfect with `no` | `She's had no food.` | Only the object expression changes. |
| Present perfect with `none` | `She's had none.` | `None` replaces the complete object noun phrase. |
| Animal pronoun | `The dog ... It ...` | Use `it` when the animal's sex is not specified. |
| Viewpoint change | `Have you ...? No, I haven't ...` | Change `you` to `I` when answering about yourself. |

## Key takeaway

- Keep the question's subject and main verb when rewriting with `any`, `no`, and `none`.
- Use `no + noun`, but use `none` without the noun.
- For `the dog`, the neutral replacement pronoun is `it`: `It hasn't eaten any bones.`
