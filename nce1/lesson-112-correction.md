## Usage table

| Pattern | Example | Practical reminder |
|---|---|---|
| Equal age | `Scott is as old as Jill.` | Use `as + adjective + as` when the values are equal. |
| Lower age | `William is not as old as Mary.` | `A is not as old as B` means A is younger than B. |
| Equal weight | `Marie is as heavy as Scott.` | Check that the two weights are identical. |
| Lower weight | `Marie is not as heavy as Jim.` | The first person must weigh less than the second person. |
| Equal height | `Marie is as tall as Jim.` | Use both `as` words around the adjective. |
| Lower height | `Scott is not as tall as Jim.` | The first person must be shorter than the second person. |
| Completing `is as ...` | `Jill is as heavy as Carol.` | If the prompt already supplies the first `as`, enter `heavy as Carol`. |
| Completing `is not ...` | `Jill is not as heavy as Marie.` | If the prompt ends at `not`, enter the complete phrase `as heavy as ...`. |

## Key takeaway

- Check the numerical relationship in the table before choosing a name.
- Equality requires the full pattern `as + adjective + as`.
- In a negative comparison, the first value must be lower: `Marie is not as heavy as Jim` because 55 kg is less than 57 kg.
