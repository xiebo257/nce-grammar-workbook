## Usage table

| Pattern | Example | Practical reminder |
|---|---|---|
| `want + object + to + verb` / `don't want + object + to + verb` | `I want you to shut the door. I don't want you to shut the window.` | Always include `to` before the verb. Use a period between the positive and negative sentences. |
| `tell + object + to + verb` / `tell + object + not to + verb` | `Tell him to be careful. Tell him not to make any mistakes.` | In the negative, use `not to` (not `not`) before the verb. |
| Pronoun shift for possessive | `your` → `his`/`her`/`their` | Match the possessive to the new object pronoun. |
| Object pronoun for second mention | `your answers` → `them`, `your homework` → `it` | Use the correct pronoun when referring back to the original noun. |
| Spelling | `remember`, `in the` | Double-check common words: `remember` has `e` before `m` in the second syllable; `in the` is two words. |
