## Usage table

| Pattern | Meaning | Example |
|---|---|---|
| `will` → `would` | future → conditional (backshift) | `I will do it` → `he would do it` |
| `shall` → `would` | first-person future → conditional | `I shall meet` → `she would meet` |
| `can` → `could` | ability modal backshift | `You can watch` → `he could watch` |
| `may` → `might` | possibility modal backshift | `I may go` → `he might go` |
| `you` → `me` | listener (reporter) → first person | `help you` → `help me` |
| `your` → `my` | listener's possessive → first-person possessive | `your teacher` → `my teacher` |
| `might` → `may` | reverse backshift (indirect → direct) | `he might know` → `I may know` |

## Key takeaway

- Modals backshift in reported speech: `will` → `would`, `shall` → `would`, `can` → `could`, `may` → `might`.
- **Second-person pronouns (`you`, `your`) must shift to match the reporter** when the reporter is the listener. `you` → `me`, `your` → `my`. Items 3, 4, and 7 all failed on this — the `you`/`your` was left unchanged or shifted to the wrong person.
- When converting indirect → direct, reverse the modal shift (`would` → `will`/`shall`, `might` → `may`) and restore the original pronouns (`me` → `you`, `my` → `your`).
- For first-person future, both `shall` and `will` backshift to `would`; the answer key may prefer `shall` but `will` is also grammatically valid.
