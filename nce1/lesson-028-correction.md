## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `Where` (location) | `Where are the tickets?` — *They're in the kitchen.* | Asks for a place. Answer uses a preposition of location. |
| `Whose` (possession) | `Whose is this pen?` — *It's Anna's.* | Asks who owns something. Answer uses a possessive form (`'s`). |
| `Who` (person identity) | `Who is that young woman?` — *That's Jane.* | Asks for a person's identity. Answer is a name or person. |
| `What` (thing identity) | `What is there near the window?` — *An armchair.* | Asks for a thing's identity. Use `What` (not `Who`) when the answer is a non-person. |
| `What` + noun (classification) | `What nationality`, `What make`, `What colour` | `What` is fixed before classification nouns — nationality, make, colour. |
| `Which` (selection from a set) | `Which ones? These?` | Used when choosing from known options. |
| `some` (affirmative) | `There are some magazines on the table.` | Use in affirmative statements to indicate an unspecified quantity. |
| `any` (question / negation) | `Are there any pictures?` / `There aren't any magazines.` | Use in questions and negative statements. `any` = it doesn't matter which. |
| `They're` for plural location | `They're in the living room. They're on the table.` | Plural subject → `They're` + prep + location. Two cues → two sentences. |
