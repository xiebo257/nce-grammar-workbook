## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| Third-person singular present simple | `Spring comes in March.` / `It rains sometimes.` / `It snows in December.` | Add `-s` to the verb for `he`/`she`/`it`/[singular subject]: `come`→`comes`, `rain`→`rains`, `snow`→`snows`, `shine`→`shines`. |
| Frequency adverb after `be` | `It's always hot.` / `He's sometimes late.` / `They are often tired.` | With `be` verbs, the adverb goes **after** `be`: `is always`, `are often`, `'s sometimes`. |
| Frequency adverb before action verb | `It often snows.` / `It sometimes rains.` | With action verbs, the adverb goes **before** the verb: `often snows`, `sometimes rains`. |
| `When...?` answer pattern | `When does spring come?` → `Spring comes in March.` | Restate the subject + verb (with `-s`) + the cue (season/month). |
| `What's the climate/weather like?` | `What's the weather like in summer?` → `It's hot in summer.` | Answer with `It's [adjective] in [season]`. |
| `Does...?` negation + correction | `Does it always snow in December?` → `No, it sometimes snows in December.` | Negate with `No,` + frequency adverb + verb (with `-s`). |
| Present continuous for current state | `What's the weather like today?` → `It's raining.` | Use present continuous (`is + verb-ing`) for weather happening right now. |
