## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `must` (obligation) | `I must be early for school.` / `They must speak English.` | `[Subject] must + base verb`. Used for strong obligation/necessity. |
| `mustn't` (prohibition) | `I mustn't be late.` / `They mustn't speak Chinese.` | `[Subject] mustn't + base verb`. Contraction of `must not`. The `t` after the apostrophe is required: `mustn't`, not `mustn's`. |
| Pronoun substitution (`one`/`it`) | `put on a dirty one` / `forget it` | Replace a repeated noun with `one` (singular countable) or `it` (specific reference). |
| Short answer: `Yes, [pronoun] must.` | `Yes, you must.` / `Yes, he must.` | Echo `must` with the matching pronoun: `I`→`you`, `you`→`I`, `he`→`he`. |
| Short answer: `No, [pronoun] mustn't.` | `No, they mustn't.` / `No, you mustn't.` | Echo `mustn't` with the matching pronoun. |
| `What's the matter with...?` → `[Pronoun] has/feels [illness].` | `He has a cold.` / `He feels ill.` / `She has a bad toothache.` | Match pronoun to the subject. `have` → `has` (third-person singular); `feel` → `feels` (third-person singular); `be` → `is`/`'s`. |

## Key takeaway

- **Q3 — spelling `mustn's` → `mustn't`.** The contraction of `must not` is `mustn't` — the apostrophe replaces the missing `o` in `not`, and the `t` stays: `must` + `n't` = `mustn't`. The learner wrote `mustn's` (with `s` instead of `t`). This changes the word — `mustn's` is not a valid English word. **Remember: `not` → `n't` always ends with `t`: `mustn't`, `doesn't`, `isn't`, `aren't`.**
- **Q9 — spelling `shcool` → `school`.** Letters `c` and `h` are transposed: s-h-c-o-o-l → s-c-h-o-o-l. "School" is one of the most common English words — proofread carefully.
