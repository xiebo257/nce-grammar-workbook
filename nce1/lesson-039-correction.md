## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| Imperative + negation split | `Use a pen, please. Don't use a pencil.` | Split "X, not Y" into "X, please. Don't Y." — add `please` to the affirmative, `Don't` to the negative. |
| `Don't put… / Put…` frame | `Don't put the dishes on the shelf. Put them in the cupboard.` | Negate the first location, then affirm the second with a pronoun (`it`/`them`). |
| Pronoun substitution: singular → `it` | `your book` → `it`; `that rug` → `it`; `the lamp` → `it` | Replace a singular object with `it` in the second sentence. |
| Pronoun substitution: plural → `them` | `your shoes` → `them`; `the bottles` → `them`; `the newspapers` → `them` | Replace a plural object with `them` in the second sentence. |
| Article expansion from cue shorthand | `near bed` → `near the bed`; `in cupboard` → `in the cupboard` | Cue shorthand drops articles; expand to `the + noun` in the full sentence. |
| Phrasal verb form 1: particle + object | `putting on his trousers` / `turning off the cooker` | Particle stays before the object: `verb + particle + object`. |
| Phrasal verb form 2: object + particle | `putting his trousers on` / `turning the cooker off` | Particle moves to the end: `verb + object + particle`. The particle appears **once** — never twice. |
| Phrasal verb form 3: pronoun + particle | `putting them on` / `turning it off` | With a pronoun, the particle **must** go after it: `verb + pronoun + particle`. |

## Key takeaway

- **Q18 — missing article `the`.** The cue `in wardrobe` is shorthand; the full sentence needs `in **the** wardrobe`. Compare Q17 where `in cupboard` was correctly expanded to `in the cupboard`. **Rule: when expanding cue shorthand, add `the` before specific nouns (bed, door, wardrobe, cupboard, shelf, desk).**
- **Q26 — duplicated particle `off`.** "turning **off** the cooker **off**" has `off` twice. In form 2 (object + particle), the particle moves from before the object to after it — it doesn't copy, it moves. "turning the cooker **off**" (one `off`). **Rule: the particle appears exactly once in each form.**
- **Q22 — extra space.** "on ." has a space before the period. A minor typo — close the sentence directly after the last word: "on."
