## Usage table

| Pattern | Meaning | Example |
|---|---|---|
| `can't have + past participle` | impossibility about the past | `You can't have tried very hard.` |
| `must have + past participle` | strong deduction about the past | `He must have passed all the exams.` |
| `must have been + -ing` | deduction about a past ongoing action | `They must have been walking in the park.` |
| `can't have been + adjective/noun` | impossibility about a past state | `He can't have been ill yesterday.` |

## Key takeaway

- Use `can't have + past participle` when a past event is impossible (source clause starts with "I don't believe ...").
- Use `must have + past participle` for a strong conclusion about something that happened earlier (source clause starts with "I think ...").
- For past ongoing actions, use `must have been + -ing` / `can't have been + -ing`.
