## Usage table

| Pattern | Meaning | Example |
|---|---|---|
| `He wants to know + wh-word + subject + verb` | indirect wh-question | `He wants to know where I live.` |
| `He wants to know if + subject + verb` | indirect yes/no question | `He wants to know if I enjoyed the film.` |
| `do/does + subject + verb` → `subject + verb(s)` | present simple question → statement | `do you live` → `I live`; `does she want` → `she wants` |
| `did + subject + verb` → `subject + past tense verb` | past simple question → statement | `did they go` → `they went`; `did you do` → `I did` |
| `you` → `I/we/me` | pronoun shift for listener | `your dresses` → `my dresses` |
| `I/my/me` → `he/his/him` | pronoun shift for speaker | `my party` → `his party` |

## Key takeaway

- For indirect questions, use statement word order (subject + verb), not question word order.
- **When the direct question uses `did`, remove `did` and put the main verb in past tense**: `did they go` → `they went`, `did you have` → `I had`, `did you do` → `I did`. Items 18, 20, and 23 all failed on this — the past tense was not applied.
- For yes/no questions, introduce with `if` and use statement word order.
- **`you all` (plural) → `we`** (plural), not `I` (singular) — item 29.
