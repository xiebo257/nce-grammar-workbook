## Usage table

| Pattern | Example | Practical reminder |
|---|---|---|
| Short adjective comparative | `warm → warmer` | Add `-er`; keep every letter of the base adjective. |
| Short adjective superlative | `warm → warmest` | Add `-est` and normally use `the`. |
| Longer adjective comparative | `more difficult than` | Use `more + adjective + than`. |
| Longer adjective superlative | `the most difficult of all` | Use `the most + adjective`, not `the + adjective` alone. |
| Lower degree | `less beautiful than`; `the least beautiful` | Use `less` for comparison and `the least` for the lowest degree. |
| Irregular comparison | `good → better`; `bad → worse → worst` | Memorize these forms; do not add `-er/-est`. |
| Equality comparison | `as fast as` | Use `as + adjective + as`. |
| Negative equality | `not as fast as` | This can express the opposite of a comparative: `slower than`. |
| Intensified comparative | `much better` | `Much` can strengthen a comparative, but not a basic adjective here. |

## Key takeaway

- Spell `warm → warmer` with both letters from the base adjective.
- Long-adjective superlatives require `the most`: `the most difficult`.
- Your `more/less`, `most/least`, irregular, and `not as ... as` comparison patterns are otherwise accurate.
