## Usage table

| Pattern | Meaning | Example |
|---|---|---|
| `will` → `would` | future → conditional (backshift) | `I will have dinner` → `he would have dinner` |
| `can` → `could` | ability modal backshift | `I can get tickets` → `she could get tickets` |
| `may` → `might` | possibility modal backshift | `you may get` → `she might get` |
| `today` → `that day` | time reference shift | `do ... today` → `do ... that day` |
| `here` → `there` | place reference shift | `be here` → `be there` |
| `you` → `him/her/them/me` | listener pronoun shift | `with you` → `with her` (listener is `her`) |
