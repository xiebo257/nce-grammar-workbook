## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `Yes, [pronoun] can.` (affirmative) | `Can you bring me some books?` → `Yes, I can.` | Echo `can` with the matching pronoun: `you`→`I`, `we`→`we`, `he`→`he`, `she`→`she`, `I`→`you`. |
| `No, [pronoun] can't.` (negative) | `Can we eat grass?` → `No, we can't.` | Echo `can't` (contraction of `cannot`) with the matching pronoun. |
| `I` → `you` shift in short answers | `Can I turn off the television?` → `Yes, you can.` | When the speaker asks about themselves (`Can I...?`), the listener answers with `you`: `Yes, you can.` |
| Pronoun gender for names | `Bob` → `he`; `Linda` → `she` | Male names (Bob, Mike, John, Sam, David) → `he`. Female names (Linda, Ann, Mary, Kathy, Jane) → `she`. |
| `Who can...?` → `[Subject] can.` | `Who can speak Korean? (I)` → `I can.` | Answer with the cue's subject + `can`. Capitalize if it starts the sentence. |
| Polite request transformation | `Open the door!` → `Can you open the door, please?` | Wrap the imperative in `Can you..., please?` to make it polite. |
| Phrasal verbs in polite requests | `Turn off the light!` → `Can you turn off the light, please?` | Keep the particle + object together: `turn off the light`, `turn on the tap`, `take off your shoes`. |
| Double objects in polite requests | `Give me the teapot!` → `Can you give me the teapot, please?` | Keep both objects: `give me the teapot`, `show me the letter`. |
