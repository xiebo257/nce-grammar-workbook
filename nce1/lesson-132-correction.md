## Usage table

| Pattern | Meaning | Example |
|---|---|---|
| `may + base verb` | present/future possibility | `His cold may get worse.` |
| `may be + -ing` | ongoing possibility now | `They may be having a lesson.` |
| `may not + base verb` | negative possibility | `She may not be at home.` |
| `may have + past participle` | past possibility | `A thief may have broken in.` |
| `may have been + complement` | past state possibility | `He may have been in the garden.` |

## Key takeaway

- Use `may + base verb` for a present/future possibility that justifies the `had better` advice.
- Use `may have + past participle` for a past possibility that explains the current concern.
- Negative possibility uses `may not + base verb` (e.g. `She may not be at home.`), not `may don't`/`may doesn't`.
- For an ongoing action, use `may be + -ing`; for a past state, use `may have been + complement`.
