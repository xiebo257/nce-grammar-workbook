## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `a`/`an` (first mention, indefinite) | `a book`, `an orange bottle`, `an electric cooker` | Use for singular countable nouns introduced for the first time. `an` before a vowel sound. |
| `the` (second mention / specific) | `The bottle is full.`, `Give me the book.` | Once a noun is introduced (`a bottle`), refer to it with `the`. |
| `the` in fixed phrases | `on the right`, `on the left`, `in the middle of`, `the matter` | These phrases require `the` regardless of first/second mention. |
| `the` with unique/specific reference | `the table`, `the shelf`, `the kitchen` | Both speakers share the context, so `the` marks the known item. |
| `a`/`an` for profession/make | `an engineer`, `a Fiat`, `an American student` | Profession, nationality, and car make take the indefinite article. |
| `the` + `one` for specific selection | `Is it the blue one?` | `one` replaces a repeat noun; `the` marks the specific item. |
| `Where is …?` / `It's on/in …` | `Where is my key? It's on the table.` | Question frame for location: `Where is + noun?` → `It's + prep + location.` |
| `in` vs `on` for location | `in the kitchen/schoolbag/middle`; `on the table/book/bed/television` | `on` = surface; `in` = enclosed/contained; `in the middle of` is fixed. |
