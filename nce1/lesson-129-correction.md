## Usage table

| Pattern | Meaning | Example |
|---|---|---|
| `must have + past participle` | strong deduction about the past | `They must have been tired.` |
| `can't have + past participle` | impossibility about the past | `He can't have been there.` |
| `had better + base verb` | strong advice | `You'd better take a taxi.` |
| `had better not + base verb` | strong negative advice | `You'd better not go out.` |
| `have a bath/haircut` | common fixed expressions | `He'd better have a haircut.` |

## Key takeaway

- Use `must have + past participle` for a strong conclusion about something that happened earlier.
- Use `can't have + past participle` when a past event is impossible.
- Use `had better + base verb` for advice, and put `not` immediately after `better` for negative advice.
