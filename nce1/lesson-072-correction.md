## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `When did...?` → `[Pronoun] [verb-ed] [object] [time].` | `I aired my room yesterday morning.` | Restate subject (as pronoun) + verb (past `-ed`) + object + time cue. Pronoun shifts: `you`→`I`, `your`→`my`. |
| Reflexive pronoun shift | `yourselves` → `myself` | When `you` shifts to `I`, the reflexive shifts too: `yourselves` (plural 2nd) → `myself` (singular 1st). |
| Past tense formation | `aired`, `called`, `arrived`, `telephoned`, `played`, `painted`, `enjoyed`, `washed`, `dusted`, `dried` | Add `-ed` to most verbs. `-e` ending → add `-d`. Consonant+`y` → `i`+`-ed`. Vowel+`y` → add `-ed`. |
| Section II two-line frame | `Jack painted the chairs yesterday. He painted the tables.` | Line 1: `[Subject] [verb-ed] the [object] yesterday.` Line 2: `[Pronoun] [verb-ed] the [cue].` |
| `the` + object in Section II | `the chairs`, `the shelves`, `the glasses`, `the cooker`, `the cups` | Add `the` before the object noun in both lines (unless possessive: `her clothes`). |
