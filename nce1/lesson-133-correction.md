## Usage table

| Pattern | Meaning | Example |
|---|---|---|
| `is/am` → `was` | present → past (backshift) | `I'm working` → `she was working` |
| `have done` → `had done` | present perfect → past perfect | `We have finished` → `they had finished` |
| `did` → `had done` | simple past → past perfect | `I ran` → `he had run` |
| `I` → `he/she` | first person → third person | `I'm sure` → `he was sure` |
| `you` → `he/she/they` | second person → matching third person | `you are wrong` → `she was wrong` |
| `say to X` → `tell X that` | reporting verb change | `said to me` → `told me` |

## Key takeaway

- When converting direct → indirect: shift tense one step back (`is` → `was`, `have done` → `had done`, `did` → `had done`), and shift pronouns (`I` → `he/she`, `you` → the matching third person for the listener).
- When converting indirect → direct: reverse the tense shift and restore the original pronouns (`he/she` → `I`, `he/she` for the listener → `you`).
- **Watch pronoun shifts carefully** — items 19 and 26 both failed on pronoun conversion: `you` → `he` (item 19) and `him` → `you` (item 26).
- **Capitalise the first word inside quotation marks** — items 21, 22, 24, 29 all left the first word lowercase.
- When two source tenses can backshift to the same indirect form (e.g. `was waiting` and `has been waiting` both → `had been waiting`), either is grammatically valid; the answer key's choice is just the preferred one.
