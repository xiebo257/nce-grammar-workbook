## Usage table

| Pattern | Example | Practical reminder |
|---|---|---|
| One owned thing | `It isn't hers. It's his.` | Use `it is`/`it isn't` for one object or an uncountable noun. |
| Multiple owned things | `They aren't mine. They're hers.` | Use `they are`/`they aren't` for plural objects, including `trousers`. |
| Named male owner | `John's bag` -> `his` | Replace a male owner's noun phrase with possessive pronoun `his`. |
| Named female owner | `Mary's bag` -> `hers` | Replace a female owner's noun phrase with possessive pronoun `hers`. |
| Multiple owners | `Mr. and Mrs. Blake's flat` -> `theirs` | Two or more owners take `theirs`, even when the owned object is singular. |
| `your` viewpoint change | question `yours` -> answer `mine` | What the questioner calls `yours`, the respondent calls `mine`. |
| `my` viewpoint change | question `mine` -> answer `yours` | What the questioner calls `mine`, the respondent calls `yours`. |
| Shared ownership | question `ours` -> answer `ours` | When both speakers are included, `ours` normally remains `ours`. |
| Possessive pronouns | `mine`, `yours`, `his`, `hers`, `ours`, `theirs` | These forms stand alone and never take apostrophes. |
