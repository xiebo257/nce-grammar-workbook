## Usage table

| Pattern | Meaning | Example |
|---|---|---|
| `can't be` | logically impossible | `You can't be serious.` |
| `must be` | strong logical conclusion | `You must be joking.` |
| `can't/must + base verb` | deduction about an action or state | `She must live far away.` |
| `can't/must be + -ing` | deduction about an action now | `They must be playing.` |
| prompted alternative | replace the rejected possibility | `not a lawyer; an artist` |

## Key takeaway

- Use `can't` when the evidence makes something impossible and `must` when the evidence strongly supports it.
- Read both halves of the context before choosing the modal; Question 1 deliberately contrasts the two conclusions.
- In the second section, reject the proposed answer and use the alternative in parentheses.
