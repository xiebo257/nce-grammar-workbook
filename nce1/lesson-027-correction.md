## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `in` (enclosed / contained) | `in a school`, `in the classroom`, `in the room`, `in the cupboard` | Use for spaces that enclose or contain — rooms, buildings, containers. |
| `on` (surface) | `on the table`, `on the wall`, `on the left/right`, `on the shelf` | Use for flat surfaces. `on the left/right` is a fixed phrase. |
| `near` (close to, beside) | `near the table`, `near the open window`, `near the door` | Use for proximity without contact — a person standing close to something. |
| Singular → plural statement | `There's a girl…` → `There are some girls…` | `There's a/an + singular` → `There are some + plural`. Change the noun to plural; keep the article as `some`. |
| Singular → plural question | `Is there a chair…?` → `Are there any chairs…?` | `Is there a/an + singular` → `Are there any + plural`. Change `a/an` to `any`; pluralize the noun. |
| Irregular plurals | `policewoman` → `policewomen`; `air hostess` → `air hostesses` | `woman` → `women` is irregular; nouns ending in `-ss` add `-es`. |
| `one` as noun substitute | `some blunt ones`, `some dirty ones` | `one(s)` replaces the repeated noun to avoid repetition — "some blunt pencils" → "some blunt ones". |
| Section III Q&A frame | `Are there any [adj] [noun-plural] [prep] [location]? No, there aren't any [adj] [noun-plural] [prep] [location]. There are some [adj2] ones [prep2] [location2].` | Three parts: question → negation → correction with `ones`. Every content word must match the new prompt — do not reuse a prior item's words. |
