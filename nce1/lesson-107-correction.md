## Usage table

| Pattern | Example | Practical reminder |
|---|---|---|
| Doubling consonant (one-syllable, vowel + consonant) | `hot → hotter/hottest`, `big → bigger/biggest`, `thin → thinner/thinnest` | Double the final consonant before `-er`/`-est`. |
| `y` → `i` | `heavy → heavier/heaviest`, `easy → easier/easiest`, `lazy → lazier/laziest` | Change `y` to `i` before `-er`/`-est`. |
| Silent `e` | `large → larger/largest`, `nice → nicer/nicest` | Just add `-r`/`-st`; no extra letter. |
| Comparative with `than` | `he's thinner than his sister` | Use `adj + -er + than` for two-item comparison. |
| `one`/`ones` as pronoun | `than this one`, `than these ones` | `one`/`ones` must have a determiner (`this`, `that`, `the`, `these`, `those`) before it. |
| Possessive pronoun `hers` | `smarter than hers` | `hers` = `her dress`; no noun needed after. |
| Superlative with `the ... of all` | `It's the lowest of all the chairs.` | Use `the + adj + -est + of all the + noun`. |
