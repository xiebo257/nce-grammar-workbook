## Key Takeaway

1. **can/can't + base verb**: after can and can't, always use the base form — no -s, -ing, or -ed. "He can **speak**" (not "speaks"), "she can't **write**" (not "writes").
2. **Pronoun substitution**: use **it** for things/animals, **he/she** for people, **one** to replace a noun (a box → this one, a book → the thick one).
3. **Ellipsis with "one"**: "a small house" → "a big **one**" (don't repeat "house"). "This light box" → "that heavy **one**" (don't repeat "box").
4. **Object pronoun after verb**: "speak Japanese" → "can't write **it**" (not "can't write Japanese" — unnecessary repetition).
