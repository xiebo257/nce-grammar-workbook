## Usage table

| Pattern | Example | Practical reminder |
|---|---|---|
| `have to` — present necessity | `We have to hurry. We are very late.` | External obligation in the present. |
| `don't need to` — present no necessity | `We don't need to hurry. There is plenty of time.` | Absence of obligation in the present. |
| `didn't need to` — past no necessity | `He didn't need to do any homework last night.` | Absence of obligation in the past. |
| Tense agreement in cause-result | `I didn't need to buy both so I bought only one.` | When the result clause is past, the cause clause must match. |
| Present state from past cause | `I don't need to buy shoes because my mother bought some yesterday.` | Present `don't need to` is fine when the state is current and the past `because`-clause explains it. |
| `have to` + main verb | `you won't have to do it` | `have to` is semi-modal; it needs a main verb (`do`, `sweep`, etc.). |
| `do it` vs `do them` | `don't need to do it` / `don't need to do them` | `Do it` treats the task as a unit; `do them` refers to the objects directly. Both are valid. |
| `won't have to` — future no necessity | `you won't have to do it then, either` | Future absence of obligation; use `either` in negative extensions. |
| `shall have to` — first-person future necessity | `Then I shall have to sweep it tomorrow.` | `shall` with first person, `will` with second/third. |

## Key takeaway

- Match the tense of the blank to the surrounding clause: past context (`bought`, `yesterday`, `last night`) takes `didn't need to`; present context takes `don't need to` or `have to`.
- Read the whole sentence before choosing: `There is a bus coming` signals no necessity, not obligation.
- `have to` is semi-modal — it always needs a main verb (`have to do it`, not `have to it`).
- `do it` (the task) and `do them` (the objects) are interchangeable in the dialogue pattern.
