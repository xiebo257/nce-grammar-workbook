## Usage table

| Pattern | Example from this lesson | Practical reminder |
|---|---|---|
| Regular plural with `-s` | `assistant -> assistants`; `nurse -> nurses` | Add `-s` to most countable nouns. |
| Endings `-s`, `-ss`, `-x`, `-ch` | `class -> classes`; `dress -> dresses`; `box -> boxes`; `watch -> watches` | Add `-es` after these endings. |
| `-f/-fe` change in `housewife` | `housewife -> housewives` | Keep the full spelling `house-`; do not write `hosewives`. |
| Irregular `man -> men` | `postman -> postmen`; `milkman -> milkmen` | Compounds ending in `-man` usually change to `-men`. |
| Irregular `woman -> women` | `woman -> women`; `policewoman -> policewomen` | Compounds ending in `-woman` change to `-women`. |
| Plural subject with `be` | `They are nurses.`; `We're postmen.` | Use `are` with `they/we`, not singular `is`. |
| Demonstrative plural | `That policeman is tall. -> Those policemen are tall.` | Change `that -> those` when making the sentence plural. |
| Viewpoint change | `What are your jobs? -> We're policewomen.` | In an answer, change `your` to the speaker's appropriate subject, such as `we`. |

## Key takeaway

- Memorize the irregular job nouns: `man -> men`, `woman -> women`, `postman -> postmen`, `policeman -> policemen`, and `policewoman -> policewomen`.
- Check spelling carefully in `housewife -> housewives` and `assistant -> assistants`.
- When rewriting a sentence in the plural, change all linked forms: `that -> those`, singular noun -> plural noun, and `is -> are`.
