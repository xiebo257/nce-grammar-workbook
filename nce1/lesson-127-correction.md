## Usage table

| Pattern | Meaning | Example |
|---|---|---|
| `can't be/do` | logical impossibility | `She can't be fifty.` |
| `must be/do` | strong logical deduction | `They must be students.` |
| `must + base verb` | obligation | `I must read this book.` |
| `can + base verb` | ability | `She can write well.` |
| `must be + -ing` | deduction about an action now | `He must be having a bath.` |
| `can't be + -ing` | current action judged impossible | `He can't be watching TV.` |
| possessive adjective | possession before a noun | `your son`, not `you son` |

## Key takeaway

- `Must` can express either a strong deduction or an obligation; context distinguishes them.
- `Can't` expresses logical impossibility in this lesson, while `can` expresses ability.
- Modals take a base form: `must have`, `can write`, `can't cost`; ongoing actions use `be + -ing`.
- Use `your` before a noun: `your son`.
