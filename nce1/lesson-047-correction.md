## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `Yes, I do. Give me [quantity], please.` | `Give me three pencils, please.` | Affirmative answer + request with the cue's quantity. `one` → `a`/`an` (singular). |
| `No, I don't. I don't like [noun].` | `I don't like whisky.` | Negative answer + reason (dislike). |
| `Yes, please. I like [noun].` | `I like tea.` / `I like biscuits.` | Accept + express preference. Drop the measure phrase: `a cup of tea` → `tea`. Plural nouns stay plural. |
| `No, thank you, but I want some [alternative].` | `but I want some beer.` | Decline politely + offer alternative with `some`. |
| `No, I don't. But I like [alternative] in/on my [noun].` | `But I like milk in my coffee.` | Negate preference + state alternative. Possessive shift: `your` → `my`. |
| `one` → `a`/`an` | `one glass` → `a glass`; `one ice cream` → `an ice cream` | When the quantity is one, use `a` (consonant) or `an` (vowel sound). |
| Measure phrase expansion | `a large bar` → `a large bar of chocolate` | The cue's measure word + `of` + the noun from the question. |
| Possessive shift `your` → `my` | `your coffee` → `my coffee`; `your bread` → `my bread` | When the answer speaks from the first-person perspective, `your` becomes `my`. |
