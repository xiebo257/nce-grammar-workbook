## Usage table

| Pattern | Meaning | Example |
|---|---|---|
| `if + present simple, can + base verb` | type 1 with `can` (ability) | `If you have money, you can buy that bike.` |
| `if + present simple, will + base verb` | type 1 with `will` (future) | `If you win the prize, you will get money.` |
| `if + present simple, must + base verb` | type 1 with `must` (obligation) | `If you come back late, you must tell me.` |
| third-person singular in if-clause | add `-s`/`-es` | `If she doesn't sweep`, `If he finishes` |

## Key takeaway

- In type 1 conditionals, the main clause can use `will`, `can`, `must`, or an imperative — all are valid.
- **Third-person singular in the if-clause requires `-s`/`-es`**: `he finishes` (not `finish`). This is the same error pattern as in lesson 137 (items 8 and 27).
- Watch for typos in longer sentences: `money` (not `moeny`), `early` (not `ealy`).
