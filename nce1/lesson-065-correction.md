## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| Reflexive pronouns | `myself` (I), `yourself` (you), `himself` (he), `herself` (she), `itself` (it), `ourselves` (we), `themselves` (they) | Match the reflexive pronoun to the subject: `I`→`myself`, `he`→`himself`, `she`→`herself`, `it`→`itself`, `we`→`ourselves`, `they`→`themselves`. |
| Imperative → reflexive | `Don't cut yourself!` (directed at `you`) → `yourself` | Imperatives directed at the listener use `yourself` (singular) / `yourselves` (plural). |
| Habitual vs unusual | `I usually do my homework at seven thirty in the evening, but this evening I'm not going to.` | Present simple with `usually` (habitual) + `but this [period]` + `isn't/aren't going to` (negation for the current period). |
| Third-person singular `-s`/`-es` in habitual clause | `Linda usually gets up…` / `He usually goes to bed…` / `My mother usually cooks…` | Singular subject → `usually` + verb`-s`/`-es`: `gets`, `goes`, `cooks`. |
| Plural base form in habitual clause | `They usually walk…` / `We usually eat…` | Plural subject → `usually` + base verb: `walk`, `eat` (no `-s`). |
| `this [period]` for current period | `this morning`, `this afternoon`, `this evening` | Use `this` + morning/afternoon/evening for the current period. But: `tonight` (not `this night`), `today` (not `this noon`). |
| Age + ability | `I'm twelve years old. I can sweep the floor.` | First line: `I'm [age] years old.` Second line: `I can [ability].` |
