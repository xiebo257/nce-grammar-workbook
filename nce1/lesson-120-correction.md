## Usage table

| Pattern | Example | Practical reminder |
|---|---|---|
| Earlier past event | `had already started` | Use past perfect for the event completed first. |
| `Already` | `had already taken him` | It emphasizes completion before the later event. |
| Very recent earlier event | `had just left` | Put `just` between `had` and the participle. |
| Double `had` | `had already had dinner` | The first `had` is auxiliary; the second is the participle of `have`. |
| Experience before then | `had never been so tired before` | Use past perfect to compare with all earlier experience. |
| Cause and result | `He had worked ... so he was tired.` | Earlier cause: past perfect; later result: past simple. |

## Key takeaway

- Exercise I specifically practices `had already + past participle`; do not omit `already` even when the tense remains grammatical.
- Exercise II uses `had just + past participle` for something completed immediately before another event.
- Check spelling carefully: `hours`, not `hourse`.
