## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| Four-line dialogue frame | `When are you going to have X?` / `[Pronoun] have/has already had X.` / `When did [pronoun] have X?` / `[Pronoun] had X [time].` | Four tenses in one dialogue: `going to` (future), present perfect (`have already had`), past question (`did have`), past simple (`had`). |
| `going to` + `have` | `When are you going to have a haircut?` | Future intention: `be going to` + base verb `have`. |
| Present perfect: `have`/`has` + `already` + `had` | `I have already had a haircut.` / `She's already had a bath.` | `have`/`has` (auxiliary) + `already` + `had` (past participle). Third-person singular: `has` (auxiliary) + `had` (past participle). |
| Past question: `did` + base `have` | `When did you have a haircut?` | After `did`, the verb reverts to **base form**: `did have`, not `did has`. |
| Past simple: `had` | `I had a haircut last Thursday.` | Simple past of `have` → `had`. |
| Present perfect negative: `haven't`/`hasn't` + `had` | `I haven't had a holiday.` / `He hasn't had a haircut.` | `haven't`/`hasn't` (auxiliary) + `had` (past participle). |
| `some`→`any` in negative | `some wine` → `any wine` | `some` in affirmative → `any` in negative present perfect. |

## Key takeaway

- **Q2 — `did he has` → `did he have`.** After `did`, the verb must be in the **base form**: `did have`, not `did has`. `did` already carries the past tense — the main verb doesn't inflect. **Rule: `did` + base form (`have`, not `has`).** This is the same rule from L53 (negation: `doesn't` + base verb). The learner correctly used `did have` in Q1, Q3-Q8, Q10 — this is a single-instance slip.
- **Q9 — `this morning` → `this evening`.** The cue says "at seven this **morning**" but the learner wrote "**this evening**." Morning ≠ evening. **Read the cue carefully before writing the answer — don't substitute time words from memory.**
- **Q17 — `a talk` → `a walk`.** Word substitution: "a **talk** with you" (conversation) vs "a **walk** with you" (stroll). These are different words — `talk` (t-a-l-k) and `walk` (w-a-l-k) differ by one letter. The present perfect structure (`haven't had`) is correct.
