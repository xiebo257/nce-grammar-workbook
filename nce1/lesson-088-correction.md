## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| Imperative → present perfect reply | `Close the window, please.` → `Yes, of course. Now I've closed it.` | Reply with present perfect (action just completed). Object → pronoun (`it`/`them`). |
| `Have you X and Y yet?` → `I've X, but I haven't Y yet.` | `I've met Ann, but I haven't met Jane yet.` | Present perfect affirmative + `but` + negative + `yet`. |
| Pronoun substitution | `the window`→`it`; `the pencils`→`them`; `the books`→`them` | Singular → `it`; plural → `them`. |
| Viewpoint shift | `for me`→`for you`; `your cold`→`my cold` | When `you` shifts to `I`, possessive shifts too: `your`→`my`, `me`→`you`. |
| Phrasal verbs in present perfect | `put on his suit` / `turned off the television` | Keep the particle + object together in present perfect. |
| `it` vs `one` for indefinite reference | "a letter" → `one` (indefinite) vs `it` (specific) | `one` = another of the same type; `it` = the same specific thing. For "a letter to her teacher" (a different letter), `one` is more natural. |
