## Usage table

| Use | Pattern | Example | Meaning / reminder |
|---|---|---|---|
| Ask about possession before naming the thing | `Whose + noun + is + this/that?` | `Whose pencil is this?` | `Whose` is a determiner. It comes directly before the noun. |
| Ask about possession when the thing is already clear | `Whose + is + this/that + noun?` | `Whose is this pencil?` | `Whose` stands alone, and the noun follows `this` or `that`. |
| Identify the owner in an answer | `It is + possessive noun.` | `It's Tony's.` / `It's my brother's.` | The final noun is understood: `Tony's [umbrella]`, `my brother's [umbrella]`. |
| Put a possessive noun before an explicitly stated thing | `possessor's + noun` | `my brother's umbrella` | Use singular `'s` to show that one person owns or is associated with something. |
| Use a possessive determiner before a noun | `my/your/his/her + noun` | `my father's car` | Possessive determiners cannot normally stand alone; they need a noun after them. |
| Change the viewpoint in a reply | `your` in the question -> `my` in the answer | `Is it your father's?` -> `It isn't my father's.` | The listener's `your` becomes the speaker's `my`. |
| Give a negative ownership answer | `No, it isn't + X's. It's + Y's.` | `No, it isn't Robert's. It's Emma's.` | `It` refers to the singular object, so use `isn't`. |
| Match the demonstrative to the prompt | `this` / `that + noun` | `this coat`; `that tie` | Keep `this` or `that` with the noun when rewriting. |

## Key takeaway

- `Whose` asks who owns something.
- Use `Whose + noun + is + this/that?` when the noun follows `whose`.
- Use `Whose is + this/that + noun?` when `whose` stands alone.
- A possessive noun can replace the repeated noun: `It's my mother's` means `It's my mother's skirt`.
- In a reply, change the viewpoint pronoun: `your father's` in the question becomes `my father's` for the speaker.

**One-line summary:** All 18 answers are correct. The main target forms are `whose` questions, singular possessive `'s`, and viewpoint changes such as `your` -> `my`.
