## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `Where was/were [subject]...?` → `[Pronoun] was [location].` | `Where was Emma...? (in her office)` → `She was in her office.` | Answer with matching pronoun + `was` + cue location only. The time/date from the question is NOT repeated. |
| `When was/were [subject] at [location]...?` → `[Pronoun] was at [location] [time].` | `When was Tom at the baker's? (at about five)` → `He was at the baker's at about five.` | Answer with matching pronoun + `was` + location (repeated from question) + time (from cue). |
| Pronoun matching: `you` → `I` | `Where were you...?` → `I was...` / `When were you...?` → `I was...` | Second person `you` → first person `I` in the answer. |
| Pronoun gender from names | Emma/Mary/Jane → `she`; Sam/Tom → `he` | Female names → `she`; male names → `he`. Sam is male (Samuel) in NCE. |
| Pronoun gender from nouns | `the old woman` → `she`; `the policewoman` → `she`; `our dog` → `it` | Noun-stated gender: `woman`/`policewoman` → `she`; animal → `it`. |
