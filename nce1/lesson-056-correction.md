## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| Third-person singular present simple | `John lives`, `He is`, `He gets`, `He goes`, `He likes`, `He plays`, `He does`, `He watches` | Singular subject (`he`/`she`/`it`/[name]) → add `-s`/`-es` to the verb. `be` → `is`. |
| Plural present simple (base form) | `They are`, `They teach`, `They go`, `They leave`, `They come`, `They read`, `They listen`, `They like` | Plural subject (`we`/`you`/`they`) → base form, no `-s`. `be` → `are`. |
| Singular vs plural verb agreement | Q1: `John lives` (singular, +s) vs Q2: `They teach` (plural, no -s) | The key distinction: singular subject → `-s`/`-es`; plural subject → base form. The learner correctly applies both patterns. |
| `usually`/`often` + base verb (first person) | `I usually eat breakfast` / `I often do my work` | With `I`, the verb is base form: `I usually eat`, `I often do` — no `-s`. |
| `often` + third-person singular verb | `My mother often cooks meals` / `He usually goes to bed` | With `he`/`she`, the adverb goes before the verb and the verb takes `-s`: `often cooks`, `usually goes`. |
| `Which...?` → `I like [item] best.` | `I like autumn best.` | Answer with `I like + [season] + best`. |
