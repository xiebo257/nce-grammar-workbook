| `for` + duration | `for two weeks`, `for a month`, `for three years` | `for` = period of time (how long). |
| `since` + point in time | `since last month`, `since January`, `since 1996`, `since last year` | `since` = starting point (when). |
| Past simple → present perfect with `for` | `went into X time ago` → `has been in X for time` | `ago` → `for + duration`. `into` → `in` (enclosed space). `to` → `to` (destination). |
| Past simple → present perfect with `since` | `went into X at time` → `has been in X since time` | Point in time (`at`, `in`, `early`) → `since + time`. |
| `been in` vs `been to` | `went into` → `been in`; `went to` → `been to` | `into` (enclosed space) → `in`; `to` (destination) → `to`. |
