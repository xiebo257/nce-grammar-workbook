## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| Present continuous: affirmative | `She's cooking a meal.` / `He's reading a magazine.` | Form: `subject pronoun + 's (is) + verb-ing`. Use for actions happening now. |
| Doubling consonant before `-ing` | `running`, `putting`, `sitting` | When a one-syllable verb ends in consonant-vowel-consonant (CVC), double the final consonant: `run` → `run-ning`, `put` → `put-ting`, `sit` → `sit-ting`. |
| Dropping `-e` before `-ing` | `typing`, `coming`, `writing` | When a verb ends in silent `e`, drop the `e` before `-ing`: `type` → `typing`, `write` → `writing`. |
| Simply adding `-ing` | `looking`, `reading`, `drinking`, `cleaning`, `turning` | For most verbs, just add `-ing`: `look` → `looking`, `drink` → `drinking`. |
| Subject pronoun agreement | `Mike` → `He`; `Mary` → `She`; `A cat` → `It`; `My mother` → `She` | Choose the pronoun that matches the subject: male → `he`, female → `she`, animal/thing → `it`. |
| Section I dialogue frame | `No, [pronoun] isn't. [Pronoun]'s in [location]. [Pronoun]'s [adjective]. [Pronoun]'s [verb+ing] [object].` | Four sentences: negation, location, state, action. Each cue maps to one sentence. |
| `at home` vs `in [room]` | `He's at home.` / `He's in the kitchen.` | `at home` (no article) for the general location; `in the [room]` for a specific room. |

## Key takeaway

- **Q8, Q14 — `putting` spelling.** `put` is a CVC verb (consonant-vowel-consonant), so the final `t` doubles before `-ing`: `put` → `put-ting`. This rule also applies to `run` → `run-ning` (Q12), `sit` → `sit-ting`. The learner wrote `puting` and `runing` — missing the doubled consonant. **Rule: CVC + `-ing` = double the last consonant.**
- **Q2 — `kitchen` spelling.** The letters `t` and `h` are transposed: `k-i-t-c-h-e-n`. Slow down on high-frequency vocabulary words.
- **Q5 — typo `is` → `in`.** `He's is the kitchen` has a typo: `is` should be `in`. The preposition `in` connects the location to the verb. Proofread for short-function-word substitutions.
- **Q3 — `classroom` compound.** `classroom` is always one word, not two. Common compound nouns: `classroom`, `living room` (two words), `bookshelf`, `cupboard`.
- **Section II — present continuous secure.** Subject pronoun selection (`He`/`She`/`It`) and `-ing` formation (including `drop-e` for `typing`) are correct across all submitted items. The errors are all spelling/typo, not grammar structure.
