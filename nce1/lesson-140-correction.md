## Usage table

| Pattern | Meaning | Example |
|---|---|---|
| `Tell me + wh-word + subject + verb` | indirect wh-question (imperative) | `Tell me where your brother is.` |
| `Tell me if + subject + verb` | indirect yes/no question (imperative) | `Tell me if you want a drink.` |
| `Do you know if/wh-word + subject + verb?` | indirect question (interrogative) | `Do you know if he likes beef?` |
| `No, I don't know if/wh-word + subject + verb.` | indirect answer | `No, I don't know if he likes beef.` |
| `did + subject + verb` → `subject + past tense verb` | past question → statement | `did they play` → `they played` |
