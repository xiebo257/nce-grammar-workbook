## Usage table

| Pattern | Example from this lesson | Practical reminder |
|---|---|---|
| First mention | `a cup`, `a glass` | Use `a/an` when introducing one nonspecific thing. |
| Reference back | `The cup`, `the glass` | Use `the` when the noun has already been identified. |
| `a` versus `an` | `a policeman`, `an engineer` | Choose by the following sound. |
| No article with nationality adjectives | `Sophie is French.` | Nationality adjectives after `be` do not need `a/an`. |
| Fixed question `What make ...?` | `What make is your car?` | Do not insert `the` before `make` in this question. |
| Subject pronouns | `I`, `he`, `they`, `we` | Use subject forms before the verb. |
| Object pronouns | `me`, `her`, `them`, `us` | Use object forms after verbs and prepositions. |
| Possessive adjectives | `my`, `your`, `their` | Put the possessive adjective directly before the noun. |

## Key takeaway

- Use `a/an` for first mention and `the` for a noun that has already been identified.
- Remember that nationality adjectives such as `French` do not take an article.
- Say `What make is your car?`, without `the` before `make`.
- Keep subject pronouns (`I`, `he`, `they`, `we`) separate from object pronouns (`me`, `her`, `them`, `us`).
