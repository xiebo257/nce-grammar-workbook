## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| Imperative → present continuous (I) | `Read your book.` → `I'm reading my book.` | Change the subject to `I'm` + verb`-ing`. **Change the possessive to match:** `your` → `my`. |
| Imperative → present continuous (we) | `Put on your coats.` → `We're putting on our coats.` | Change the subject to `We're` + verb`-ing`. **Change the possessive to match:** `your` → `our`. |
| Possessive adjective agreement | `I` → `my`; `we` → `our`; `you` → `your`; `he` → `his`; `she` → `her` | The possessive must match the subject. When the subject changes, the possessive changes with it. |
| `going to` future | `I'm going to make a bookcase.` | Form: `subject + am/is/are going to + base verb`. Used for planned future actions. |
| Two-action `Then` frame | `I'm going to make a bookcase. Then I'm going to paint it.` | First action, then `Then` + second action. `Then` is lowercase mid-sentence. |
| CVC doubling in `-ing` | `sitting`, `putting` | `sit` → `sit-ting`, `put` → `put-ting` (double the final consonant). |
| `-e` dropping in `-ing` | `making`, `coming` | `make` → `making`, `come` → `coming` (drop silent `e`). |

## Key takeaway

- **Q4, Q5, Q7, Q10 — possessive not shifted.** When the imperative `Read your book` becomes `I'm reading...`, the subject changes from `you` to `I`. The possessive must follow: `your` → `my`. The learner correctly applied this rule in Set 2 (`your` → `our` in Q11–Q14, Q18) but missed it in Set 1. **Rule: when the subject changes, every possessive adjective in the sentence changes to match.**
- **Q26 — capital `We're` mid-sentence.** After `Then`, `we're` is mid-sentence and should be lowercase. `Then` connects two clauses within the same sentence structure; it doesn't start a new sentence.
- **Section II — `going to` future secure.** All 8 items correctly use `going to` + base verb with the `Then` two-action frame. Cues that already contain possessives (`my homework`, `my father's car`, `my clothes`, `our books`) are correctly preserved.
