## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `Don't [verb]...` → `You mustn't [verb]...` | `Don't put the dishes here.` → `You mustn't put the dishes here.` | Replace `Don't` with `You mustn't` + base verb. |
| `[Verb]...` → `You must [verb]...` | `Put them on the shelf.` → `You must put them on the shelf.` | Replace the imperative with `You must` + base verb. |
| `[Cause], so [effect].` | `I don't feel well, so I'm staying at home today.` | Join cause and effect with `, so `. The effect uses the tense/modal from the cue. |
| Effect with `must` | `so I must take him to the doctor's.` | When the cue has `must`, use `must` + base verb in the effect. |
| Effect without modal (current situation) | `so I'm staying at home today.` | When the cue has no modal and describes a current action, use present continuous: `I'm going`, `he's going`. |
| Effect with `often` (habitual) | `so the tourists often go there then.` | When the cue has `often`, use present simple: `often go` (adverb + base verb for plural). |
| Third-person singular in present simple | `he goes`, `the taxi driver drives` | Third-person singular subjects (`he`, `she`, `[name]`, `the taxi driver`) require `-s`/`-es` on the verb in present simple: `go`→`goes`, `drive`→`drives`. |
| State verbs | `I don't want them.` (not `I'm not wanting`) | State verbs (`want`, `like`, `know`, `have` for possession) use present simple, not present continuous. Negation: `don't/doesn't + base verb`. |
| Never combine `be` + base verb | `I don't want` (not `I'm not want`) | `I'm` = `I am`. You cannot say "I am not want" — `am` + `want` is ungrammatical. Use `don't` + base verb for negation. |

## Key takeaway

- **Q15, Q18 — missing modal/`-s` for third-person singular.** "The taxi driver **drive**" and "he **go**" are ungrammatical — a third-person singular subject needs either a modal (`must drive`, `must go`) or the `-s` ending (`drives`, `goes`). **Rule: `he`/`she`/`it`/[name]/[singular noun] + verb`-s` in present simple, OR + modal + base verb. Never use the base form alone with a third-person singular subject.**
- **Q17 — `I'm not want` is ungrammatical.** `I'm` = `I am`, and "I am not want" mixes `be` with a base verb — this is not valid English. `want` is a state verb → use present simple negation: `I don't want them`. **Rule: never combine `be` (`I'm`/`he's`/`she's`) with a base verb. Use `don't`/`doesn't` + base verb for state-verb negation.**
- **Q13 — present simple vs present continuous.** The example uses present continuous for the effect ("I'm staying at home today"). When the cause is a current situation ("It's raining very hard"), the effect should also be current → present continuous ("I'm going to work by taxi"). Present simple ("I go") sounds habitual, not a response to current conditions.
- **Section I — fully correct.** All 9 `must`/`mustn't` rewrites are correct — the imperative → modal transformation is mastered.
- **Section II — 3/7.** The `so` conjunction is correctly used in all 7 items. The errors are in verb form: missing modal/`-s` for third-person singular (Q15, Q18) and mixing `be` with a base verb (Q17).
