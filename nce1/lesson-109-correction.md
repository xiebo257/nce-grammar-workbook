## Usage table

| Pattern | Example | Practical reminder |
|---|---|---|
| `good → better → best` | `a good mark; a better mark; the best mark` | These forms are irregular. |
| `bad → worse → worst` | `bad; worse; the worst` | Do not add `-er/-est` to `bad`. |
| `many/much → more → most` | `more friends; the most friends` | Use these for both countable and uncountable quantities. |
| `few → fewer → fewest` | `fewer mistakes; the fewest mistakes` | Use with plural countable nouns. |
| `little → less → least` | `less money; the least money` | Use for an uncountable quantity; `littler/littlest` normally describe physical size. |
| `little` / `a little` | `little milk`; `a little milk` | `Little` means almost none; `a little` means some. Both take uncountable nouns. |
| `few` / `a few` | `few people`; `a few tickets` | `Few` means almost none; `a few` means some. Both take plural countable nouns. |
| `very few` | `very few mistakes` | Never put `a` between `very` and `few`. |
| Dialogue contrast | `I've got very little.` / `I still have a little.` | The first suggests a shortage; the second says some remains. |

## Key takeaway

- Memorize the irregular quantity series: `many/much → more → most`, `few → fewer → fewest`, and `little → less → least`.
- Use `little/a little` with uncountable nouns and `few/a few` with plural countable nouns.
- After `very`, use `very little` or `very few`, never `very a little` or `very a few`.
