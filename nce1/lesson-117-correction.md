## Usage table

| Pattern | Example | Practical reminder |
|---|---|---|
| Background action | `while she was cutting` | Use past continuous for an action in progress. |
| Interrupting event | `she cut her finger` | Use past simple for the completed event. |
| `When` substitution | `When I was having a bath, ...` | `When` can replace `while` in these time clauses. |
| `Just as` | `Just as he was leaving, ...` | Use it for an event happening at the same moment. |
| Past simple of `begin` | `began to rain` | `Begin–began–begun`; use `began` alone for a past event. |

## Key takeaway

- Use past continuous for the longer background action and past simple for the event that happens during it.
- `When` and `while` can introduce the same time relationship in these exercises.
- Distinguish `began` (past simple) from `begun` (past participle), and check spelling such as `road`.
