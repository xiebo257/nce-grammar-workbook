## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `There are some` + plural countable | `There are some pencils on the desk.` | Plural countable nouns → `are` + `some`. |
| `There is some` + uncountable | `There is some paper on the shelf.` | Uncountable nouns → `is` + `some`. |
| `Are there any` + plural countable? | `Are there any magazines on the shelf?` | Plural countable → `Are there any...?` |
| `Is there any` + uncountable? | `Is there any butter on the plate?` | Uncountable → `Is there any...?` |
| Plural-only nouns: `clothes`, `trousers`, `scissors` | `Are there any clothes on the bed?` | Some nouns are always plural — they take `Are there any...?` / `No, there aren't any...`, never `Is there any...?` |
| `There are [number]` + plural countable | `There are twenty watches in the box.` | Numbers replace `some`: `There are twenty watches` (not `some twenty watches`). |
| `hundred` after a number | `three hundred pages`, `six hundred bars` | `hundred` stays singular after a number: `three hundred`, `six hundred`. No `-s` on `hundred`. |
| Measure phrases in plural | `two cups of tea`, `two pieces of paper`, `two loaves of bread`, `twelve bars of chocolate`, `ten slices of bread`, `three bottles of beer`, `six hundred bars of soap` | The measure noun takes the plural: `cup`→`cups`, `piece`→`pieces`, `loaf`→`loaves`, `bar`→`bars`, `slice`→`slices`, `bottle`→`bottles`. The uncountable noun stays singular. |

So the question is "**Are** there any clothes...?" and the negation is "No, there **aren't** any clothes..." — not "Is there any... / isn't any...". **Rule: plural-only nouns (clothes, trousers, scissors, glasses) always take `are`/`aren't`/`any`, never `is`/`isn't`/`any` as singular.**
