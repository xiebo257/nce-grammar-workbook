## Usage table

| Pattern | Example | Practical reminder |
|---|---|---|
| Positive agreement | `So can I.` | Repeat the auxiliary or modal, then use the new subject. |
| Negative agreement | `Neither did I.` | Use `neither + auxiliary/modal + subject`. |
| Be agreement | `So are my trousers.` | Match `is/are/am` to the new subject. |
| Do/does agreement | `So does her sister.` | Use `does` with he, she, it, or a singular noun. |
| Third-person negative | `She doesn't want any.` | Use `doesn't`, not `don't`, with she/he/it. |
| `any` after a negative | `didn't buy any` | `Any` follows the negative auxiliary. |
| `no` determiner | `bought no beef` | `No` comes directly before the noun. |
| `none` pronoun | `bought none` | `None` replaces the noun phrase. |

## Key takeaway

- In agreement replies, repeat the auxiliary from the original sentence and change only the subject.
- Check the new subject carefully: `you` takes `are`, while `I` takes `am`.
- Third-person singular subjects require `doesn't`, not `don't`.
- `Any`, `no`, and `none` express the same absence in different grammatical patterns.
