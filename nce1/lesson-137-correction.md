## Usage table

| Pattern | Meaning | Example |
|---|---|---|
| `if + present simple, will + base verb` | type 1 conditional (real/likely future) | `If you see him, please give him this letter.` |
| `if + present simple, imperative` | type 1 conditional with imperative | `If you finish early, please wait for me.` |
| `if + present simple, be going to` | type 1 with `be going to` (also valid) | `If it's fine, I'm going to have a swim.` |
| third-person singular in if-clause | add `-s`/`-es` | `If he falls`, `If she passes` |

## Key takeaway

- In a type 1 conditional, the **if-clause uses present simple** and the **main clause uses a future form** (`will`/`won't`/`shall`, or an imperative).
- **Main clause must be future**, not present: `Everything will be all right` (not `is all right`); `What will you say` (not `What do you say`). Items 2 and 3 used present simple in the main clause.
- **Third-person singular in the if-clause** requires `-s`/`-es`: `he falls` (not `fall`), `he passes` (not `pass`). Items 8 and 27 missed this.
