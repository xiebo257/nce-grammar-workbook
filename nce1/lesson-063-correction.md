## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `Can I...?` (requesting permission) | `Can I use your pencil?` / `Can I borrow your bike?` | `Can I + base verb + object?` — polite request for permission. |
| `How long must/can...?` → `[Subject] must/can [verb] for [duration].` | `He must stay in bed for a week.` / `You can use my bike for two weeks.` | Answer with the modal (`must`/`can`) + base verb + **`for`** + duration. The preposition `for` introduces the time period. |
| `for` + duration | `for three days`, `for about an hour`, `for eight hours`, `for about two weeks`, `for two months` | Use `for` before a time duration: "stay in bed **for** a week," "play **for** about two hours." |
| `Why mustn't...?` → `Because [pronoun] has [illness].` | `Because he has a bad cold.` / `Because she has measles.` | Answer with `Because` + pronoun + `has` (third-person singular) or `have` (first/second/plural person) + illness. |
| Pronoun matching in `Because` answers | `I`→`you`, `he`→`he`, `she`→`she`, `they`→`they` | Match the pronoun to the question's subject: `Why mustn't I...?` → `Because you...`, `Why mustn't he...?` → `Because he...` |
| `have` → `has` (third-person singular) | `she has`, `he has` | After `he`/`she`/[name], `have` → `has`. After `I`/`you`/`they`, `have` stays as `have`. |
