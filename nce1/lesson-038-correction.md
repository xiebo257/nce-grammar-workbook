## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `going to` future | `I'm going to drink tea.` / `We're going to wait for the bus.` | Form: `subject + am/is/are going to + base verb`. Use for planned actions. |
| Double negation frame | `No, I'm not, and I'm not going to work.` | Negate present continuous (`I'm not`) + negate `going to` future (`I'm not going to`). |
| Possessive shift with subject change | `your homework` → `my homework`; `your shoes` → `my shoes` | When `you` → `I`, change `your` → `my`. When `you` → `we`, change `your` → `our`. |
| Pronoun substitution (plural) | `pencils` → `them`; `baskets` → `them` | Replace plural objects with `them` to avoid repetition. |
| Pronoun substitution (singular) | `this window` → `it`; `Emma's bed` → `it` | Replace singular objects with `it` to follow the example pattern. |
| Phrasal verbs in `going to` | `turn on the television`, `put on my coat` | Keep the particle + object together: `going to + turn on + object`, `going to + put on + object`. |
