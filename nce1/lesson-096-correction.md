## Usage table

| Pattern | Example | Practical reminder |
|---|---|---|
| Past event with `ago` | `I swept the floor an hour ago.` | Use past simple before `ago`; choose the correct past form, including irregular verbs. |
| Future event with `in ... time` | `I'll cook dinner in an hour's time.` | Use `will/shall + base verb` with `in + possessive time expression`. |
| Singular possessive time | `an hour's time`, `a month's time` | Put `'s` after a singular time noun. |
| Plural possessive time | `two minutes' time`, `six months' time` | For regular plural nouns ending in `s`, put the apostrophe after the `s`. |
| Irregular past forms | `meet` -> `met`; `sweep` -> `swept`; `give` -> `gave`; `fly` -> `flew`; `sell` -> `sold`; `drive` -> `drove`; `speak` -> `spoke` | These forms do not use the regular `-ed` ending and must be memorized. |
| Clock time with `past` | `5:02` -> `two minutes past five` | Count minutes after the current hour and use `past`. |
| Clock time with `to` | `7:58` -> `two minutes to eight` | Count the remaining minutes before the next hour and use `to`. |
| Half hour | `11:30` -> `half past eleven` | Use `half past + hour` for thirty minutes after the hour. |
| Future interval calculation | `4:20` to `4:55` -> `in thirty-five minutes' time` | Subtract the current time from the stated future time, then use the possessive time phrase. |
