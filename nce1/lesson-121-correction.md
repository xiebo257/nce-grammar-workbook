## Usage table

| Pattern | Example | Practical reminder |
|---|---|---|
| Job definition | `someone who looks after sick people` | Use present simple and third-person `-s`. |
| Subject relative | `the man who is locking the door` | Use `who/that` for people; the pronoun performs the verb. |
| Object relative | `the house that we visited` | Use `that/which` for things; the pronoun receives the action. |
| People as object | `the person whom/that I asked` | Formal English uses `whom`; `who` is common in ordinary modern English. |
| Possessive detail | `the magazines that I bought` | Preserve the noun phrase and check spelling. |

## Key takeaway

- A singular job definition uses `someone who + verb-s`: `someone who makes clothes`.
- Use `who` for people and `which` for things; `that` can often replace either in defining clauses.
- Use `who/that` when the relative pronoun is the subject; use `whom/that` for a formal object relative clause.
