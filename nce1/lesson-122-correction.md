## Usage table

| Pattern | Example | Practical reminder |
|---|---|---|
| Thing as subject | `a doll which walks and talks` | Use `which/that`; the pronoun performs the verb. |
| Thing as object | `the books which I bought` | Use `which/that`; the noun receives the action. |
| Person as subject | `someone who has a phone` | Use `who/that`. |
| Person as object | `the man who I saw` | Everyday English uses `who`; formal English may use `whom`. |
| Final preposition | `the street which we walked along` | Leaving the preposition at the end is natural. |
| Reverse combination | `the person who was a stranger helped me` | Either original statement may be the main clause if both facts remain clear. |

## Key takeaway

- Use `who` for people and `which` for things; `that` is an alternative in defining relative clauses.
- Decide whether the relative pronoun is the subject or object of its clause.
- Object `who` is normal in modern English; `whom` is more formal.
