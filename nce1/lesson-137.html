NCE Grammar Practice 1

Lesson 137: A pleasant dream

I. Fill in the blanks with the correct tense of the verb given.

  1. If you _____ (see) him, please give him this letter.
  2. Everything _____ (be) all right if you win some money.
  3. What _____ you _____ (say) if you _____ (see) him?
  4. If you _____ (not arrive) early, you _____ (not get) a seat.
  5. If he _____ (stay) with me, I will not be afraid.
  6. I _____ (help) you if I can.
  7. If you _____ (not hurry), you _____ (be) late.
  8. If he _____ (fall) off that wall, he _____ (hurt) himself.
  9. We _____ (do) it if we can.
  10. If she _____ (feel) ill tomorrow, she _____ (go) and see a doctor.
  11. If you _____ (work) hard, you _____ (get) good marks.
  12. If she _____ (pass) the examination, she _____ (leave) school.

II. Answer the questions, using the cues given according to the example.

  1. What will you do if you take a long holiday next summer? (go to New York)

    If I take a long holiday next summer, I'll go to New York.

  2. How will you go if you go to New York? (by air)
  3. Which airport will you arrive at if you fly to New York? (Kennedy Airport)
  4. Where will you go if you arrive at Kennedy Airport? (Manhattan)
  5. How will you go if you go to Manhattan? (go by bus)
  6. What will you see if you go to Manhattan? (the Empire State Building)
  7. What will you do if you visit the Empire State Building? (go to the top)
  8. What will you do if you go to the top? (take some photographs of New York)

III. Combine each pair of sentences, using "if" according to the example.

  1. It's possible that you won't feel better tomorrow. /You must go to the doctor's.

    If you don't feel better tomorrow, you must go to the doctor's.

  2. It's possible that it'll be fine tomorrow. /I'm going to have a swim.
  3. It's possible that it won't rain tomorrow. /I'll go to the beach.
  4. It's possible that you'll ask him./I'm sure he'll help you.
  5. It's possible that you'll finish the test before me. /Please wait for me.
  6. It's possible that you'll see him./Please give him my best wishes.
  7. It's possible that she won't speak more loudly. /No one will hear her.
  8. It's possible that I will know the answer. /I'll tell you.
  9. It's possible that he'll pass the exam./He'll go to university.
  10. It's possible that I'll have enough money./I'll buy a car.
