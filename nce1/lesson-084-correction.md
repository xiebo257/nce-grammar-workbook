## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| Affirmative: `much`/`many` → `a lot of` | `Have you had much beer?` → `I have just had a lot of beer.` | In affirmative present perfect, use `a lot of` (not `much`/`many`). Both `much` and `many` convert to `a lot of`. |
| Negative (uncountable): `much` → `any...at all` | `We haven't had any coffee at all.` | Complete negation: `any...at all` = zero. |
| Negative (plural countable): `many` stays `many` | `They haven't had many cakes.` | Partial negation: `haven't had many` = not many, but some. |
| Present perfect + `just` | `I have just had a lot of beer.` | `have/has` + `just` + `had` (past participle). |
| Present perfect + `already` | `But I've already had dinner.` | `have/has` + `already` + `had` (past participle). Used to say something is done. |
| Pronoun substitution: `some`/`one` | `some fruit` → `some`; `a drink` → `one` | Replace `some + noun` → `some`; `a/an + noun` → `one`. Avoid repeating the full noun. |

## Key takeaway

- **Q2/Q3/Q4 — `many` not converted to `a lot of` in affirmative.** The example shows `much` → `a lot of` in affirmative. The same rule applies to `many` → `a lot of`. The learner correctly converted `much` (Q1, Q5-Q8: all uncountable) but kept `many` (Q2-Q4: all plural countable). **Rule: in affirmative present perfect, both `much` AND `many` → `a lot of`.** The learner may think `many` is acceptable in affirmative (it is in formal English), but the exercise pattern requires `a lot of`.
- **Q14 — spelling `havan't` → `haven't`.** `a` → `e`: h-a-v-**a**-n't → h-a-v-**e**-n't. The contraction of `have not` is `haven't`, not `havan't`.
- **Q21 — spelling `alread` → `already`.** Missing `y`: a-l-r-e-a-d → a-l-r-e-a-d-**y**. "Already" ends with `y`.
- **Q13/Q16 — `a lot of` vs `any...at all` in negative.** The example uses `any...at all` (complete negation = zero). The learner used `a lot of` (partial negation = not much). Both are grammatically correct, but the exercise pattern uses `any...at all`.
- **Q20/Q25 — pronoun substitution.** `some apples` → `some` (pronoun); `a swim` → `one` (pronoun). The learner kept the full nouns. Q18/Q19/Q22/Q24 correctly use pronouns. Both forms are grammatically correct, but the pattern prefers pronoun substitution.
