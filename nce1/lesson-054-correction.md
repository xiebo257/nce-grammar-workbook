## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| Nationality + origin answer | `She's French. She comes from France.` | State the nationality (from cue), then the country (derived from nationality). |
| `Where...?` answer | `She comes from Turkey.` | `[Pronoun] come(s) from [country].` Third-person singular → `comes`; plural → `come`. |
| Pronoun gender from noun | `that man` → `he`; `that old woman` → `she`; `those young men` → `they` | Match the pronoun to the noun's gender: `man` → `he`, `woman` → `she`, `men`/`tourists` → `they`. |
| Pronoun gender from name | `Sophie`/`Marie` → `she`; `Hans`/`Dave` → `he` | Female names → `she`; male names → `he`. |
| Third-person singular `-s` | `gives`, `plays`, `looks`, `comes`, `climbs`, `walks`, `wants`, `sees`, `takes`, `snows` | Most verbs: just add `-s`. Verbs ending in `-e`: add `-s` (`give`→`gives`, `shine`→`shines`). |
| Third-person singular `-es` | `teaches`, `watches`, `goes`, `does` | Verbs ending in `-ch`, `-sh`, `-ss`, `-x`, `-o`: add `-es`. |

## Key takeaway

- **Q19 — pronoun gender for "old woman".** "That old **woman**" is explicitly female — the gender is in the noun itself. The learner used `He` instead of `She`. This is different from name-based gender inference (Sophie→she, Hans→he) — here the noun "woman" directly states the gender. **Rule: `man` → `he`, `woman` → `she`, `men`/`women`/`tourists` → `they`.**
