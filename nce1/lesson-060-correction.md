## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| Measure-phrase Q&A | `Do you have any wine? Yes, I do. I have a glass of red wine.` | Ask with `any` + uncountable noun; answer with `Yes, I do. I have [measure] of [adjective] + noun.` |
| Pronoun substitution `ones` | `German cars` → `German ones`; `red apples` → `red ones` | Replace `[adj] + noun` with `[adj] + ones` to avoid repeating the noun. |
| Section II dialogue frame | `What's the time?` / `It's [time] o'clock.` / `I'm going to [action]. Do we have any [item]?` / `Yes, we do. What else do you want?` | Five-line dialogue: time → `going to` action → `Do we have any...?` → affirmative → follow-up question. |
| `going to` future | `I'm going to wash some clothes.` / `I'm going to write some letters.` | `am/is/are going to + base verb` for planned actions. |
| `Do we have any...?` | `Do we have any soap?` / `Do we have any writing paper and envelopes?` | Question form with `any` + uncountable/plural noun. Ends with `?`. |
