## Usage table

| Pattern | Example | Practical reminder |
|---|---|---|
| `want + object + to + verb` | `He wants her to close all the doors.` | The verb after the object must be a `to`-infinitive. |
| `tell + object + to + verb` | `Tell her to sweep the floor.` | Same as above for imperatives with `tell`. |
| `tell + object + not to + verb` | `Tell them not to stop.` | Negative imperative: insert `not to` before the verb. |
| `not want + object + to + verb` | `I don't want you to swim in the river.` | With `not want`, use `don't/doesn't + want + object + to + verb`. |
| Third-person singular negative | `He doesn't want`, `She doesn't want` | Use `doesn't` (not `don't`) after `he`, `she`, `it`. |
| `to be` in infinitive | `to be careful`, `not to be lazy` | `be` always needs `to` before it in this pattern: `want/tell + object + to be`. |
| Deictic `there` stays `there` | `Stay there.` → `Tell him to stay there.` | `there` refers to a specific place, not the reporter's location; do not change to `here`. |
| Reflexive pronoun shift | `yourself` → `herself`/`himself` | Match the reflexive to the new subject. |
| Possessive pronoun shift | `your` → `their` | Match the possessive to the new subject. |
