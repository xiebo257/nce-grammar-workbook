## Usage table

| Pattern | Example | Practical reminder |
|---|---|---|
| `want + object + to + verb` | `He wants her to close all the doors.` | Always include `to` before the verb — including `to be`. |
| `tell + object + to + verb` | `Tell her to sweep the floor.` | Same pattern for imperatives with `tell`. |
| `tell + object + not to + verb` | `Tell them not to stop.` | Negative imperative: `not to` before the verb. |
| `not want + object + to + verb` | `He doesn't want you to be late.` | Third-person singular: `doesn't want + object + to + verb`. |
| Deictic `there` stays `there` | `Stay there.` → `Tell him to stay there.` | `there` refers to a specific place; do not change to `here`. |
| Reflexive pronoun shift | `yourself` → `herself`/`himself` | Match the reflexive to the new subject. |
| Possessive pronoun shift | `your` → `their` | Match the possessive to the new subject. |
