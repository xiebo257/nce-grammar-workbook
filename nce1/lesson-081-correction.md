## Key takeaway

- **Q2/Q3/Q5 — `have` conversion pattern not applied.** The lesson's core point: `have` can replace both `eat` and `drink`. When two sentences use **different** verbs (`eats` + `drinks`), convert both to `have`/`has`/`had` → one verb + two objects joined by `and`. Example: "drinks coffee" + "eats bread" → "has coffee and bread." The learner kept both original verbs ("eats eggs and drinks milk") instead of converting to "has eggs and milk." **Rule: eat/drink → have (present: has/have; past: had).**
- **Q4 — spelling `saland` → `salad`.** Extra `n`: s-a-l-a-**n**-d → s-a-l-a-d. The verb pattern (same verb `eating` + `eating` → keep `eating`) is acceptable.
- **Q5 — two spelling errors.** `potetoes` → `potatoes` (missing `a`: p-o-t-**a**-t-o-e-s) and `fo` → `for` (missing `r`).
- **Q14 — third-person singular `have` → `has`.** Same recurring error type as L50/L55/L64/L71. `your child`→`He` (third-person singular) → `has`, not `have`. Also spelling `ang`→`and`.
