## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| Present continuous question | `Is Sam climbing? Yes, he is.` / `Is she drinking tea? Yes, she is.` | Form: `Is + [subject] + verb-ing? Yes, [pronoun] is.` |
| CVC doubling before `-ing` | `running`, `sitting`, `putting` | `run` → `run-ning`, `sit` → `sit-ting`, `put` → `put-ting`. Double the final consonant for CVC verbs. |
| Dropping `-e` before `-ing` | `making`, `typing` | `make` → `making`, `type` → `typing` (drop silent `e`). |
| Subject pronoun gender | `Sam` → `he`; `Kathy`/`Jane`/`Marie` → `she`; `the dog`/`the cat` → `it` | Match the pronoun to the subject's gender. **Jane is a female name → `she`.** |
| Set 1 dialogue frame | `Is [subject] [verb1-ing]? No, [pronoun] isn't. What is [pronoun] doing? [Pronoun]'s [verb2-ing] [object]. Where is [pronoun] [verb2-ing]? [Pronoun]'s [verb2-ing] [location].` | Four sentences: question → negation → correction → location. Every cue maps to one part. |
| Set 2 dialogue frame | `Who is [verb1-ing] [object]? [Person1] is. What about [Person2]? [Pronoun]'s [verb2-ing] [object2].` | Three sentences: Who-question → Person1 → What about Person2. Read the cue carefully — Person2 is the **second** name, not the first. |

## Key takeaway

- **Q13 — pronoun gender.** Jane is a female name → `she`/`her`. The learner used `he`/`he`/`he`/`he` throughout. When the subject is a name, check the gender before choosing the pronoun: `Jane`, `Kathy`, `Marie`, `Sally`, `Ann` → `she`; `Sam`, `Pedro`, `Tony`, `Jack`, `Mike` → `he`.
- **Q14 — spelling `dong` → `dog`.** The letters `o` and `g` are transposed. `dog` = d-o-g. Proofread three-letter words carefully.
- **Q15 — copy-paste.** The answer is a verbatim copy of Q14 (the dog). The prompt is about Tony sweeping/emptying a basket in the garden. When moving to the next item, re-read the cue and write a fresh answer — don't reuse the previous item's text.
- **Q16 — spelling `runing` → `running`.** `run` is a CVC verb → double the `n` before `-ing`. The learner wrote `running` correctly in "It's running." but then wrote `runing` in "Where is it runing?" — inconsistent. **Always double-check the same word when it appears twice.**
- **Q20 — wrong name `Sally` → `Ann`.** The cue is `Sally/Ann/put on her skirt` — Sally is Person1, Ann is Person2. The "What about" question must name Person2 (Ann), not repeat Person1 (Sally). Read the cue from left to right: first name → Who-question, second name → What-about question.
- **Q18, Q19, Q22 — missing final period.** A minor punctuation slip at the end of the answer. Close every sentence with a period.
