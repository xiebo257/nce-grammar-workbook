## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| `Can [subject] [verb] [item]?` | `Can Ann make tea?` | Yes/no question about ability. Use the base verb after `Can`. |
| `Yes, [pronoun] can.` / `No, [pronoun] can't.` | `Yes, she can.` / `No, he can't.` | Short answer echoes `can`/`can't` with the matching pronoun. |
| `but [pronoun] can [verb] [item3].` | `but she can make coffee.` | After negation, state what the subject CAN do with `but + pronoun + can`. |
| `Who can [verb] [item2]?` | `Who can make bread?` | Ask who has the ability the original subject lacks. |
| `[Name] can [verb] [item2].` | `John can make bread.` | Answer with the last person from the cue. |
| Pronoun gender matching | `Ann` → `she`; `Mike`/`John` → `he`; `they` → `they`; `you` → `I` | Match the pronoun to the subject's gender: female names (Ann, Mary, Kathy) → `she`; male names (Mike, John, Sam) → `he`. |
| `in front of` (facing/before) | `sitting in front of me` | Position facing or before someone/something. |
| `behind` (at the back of) | `hiding behind a tree` | Position concealed at the back of something. |
| `over` (above/across) | `flying over the wall` | Movement or position above something. |
| `along` (following the length) | `running along the wall` | Movement parallel to the length of something. |
| `on` (surface) | `on the bridge/table` | Contact with a surface. |
| `in` (contained) | `in the kettle` | Contained within something. |
| `out of` (exiting) | `coming out of the shop` | Movement from inside to outside. |
