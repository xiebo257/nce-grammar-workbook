## Usage table

| Pattern | Example | Reminder |
|---|---|---|
| Ordinal suffixes | 1st (first), 2nd (second), 3rd (third), 4th–20th (-th), 21st, 22nd, 23rd | `1` → `1st`, `2` → `2nd`, `3` → `3rd`, all others → `-th` (4th, 5th, 6th, 8th, 15th, 25th). **1 never takes `-th`.** |
| Date format | `February 5th` (month + day + ordinal suffix) | `It's [Month] [day][st/nd/rd/th].` |
| `past` (after the hour) | `a quarter past one` = 1:15 → `one fifteen` | "Past" = minutes after the hour. `quarter past one` = 1:15. |
| `to` (before the hour) | `a quarter to five` = 4:45 → `four forty-five` | "To" = minutes before the next hour. `quarter to five` = 4:45. |
| Digital time format | `four thirty`, `two thirty-five`, `ten fifty-five` | `[hour] [minutes]` — no `o'clock`, no hyphen unless compound (thirty-five). |
| `forty` (not `fourty`) | `three forty`, `four forty-five` | The number 40 drops the `u`: f-o-r-t-y. Not f-o-u-r-t-y. |
| `at` + clock time | `at ten o'clock`, `at noon`, `at ten past six` | Use `at` with specific clock times and `noon`/`night`. |
| `in` + months/seasons/parts of day | `in July`, `in spring`, `in December`, `in the morning/afternoon` | Use `in` with months, seasons, and parts of the day (morning/afternoon/evening). |
| `on` + days/dates | `on Saturday`, `on July 8th` | Use `on` with days of the week and dates (month + day number). |

## Key takeaway

- **Q2/Q3/Q5/Q10 — `1th` → `1st`.** The ordinal suffix for 1 is `-st` (first), not `-th`. This error repeats across all four dates with day = 1. **Rule: 1→1st, 2→2nd, 3→3rd, then 4th–20th all take `-th`, 21→21st, 22→22nd, 23→23rd.** Only 1, 2, 3 (and their teens: 21, 22, 23) take non-`-th` suffixes.
- **Q9 — spelling `Novemver` → `November`.** The `b` was typed as `v`: N-o-v-e-m-**b**-e-r. Proofread month names carefully.
- **Q12/Q14/Q16 — spelling `fourty` → `forty`.** The number 40 drops the `u` from "four": f-o-r-t-y, not f-o-u-r-t-y. This is a common spelling trap — "four" has a `u`, but "forty" does not. The error repeats across three items.
- **Q16 — time conversion error.** "A quarter **past** one" = 1:15 (15 minutes after 1:00), not 12:45. The learner confused "past" (after) with "to" (before). **Rule: "past" = after the hour → add minutes; "to" = before the next hour → subtract from 60.** `quarter past one` = 1:15 → "one fifteen." `quarter to one` = 12:45 → "twelve forty-five."
